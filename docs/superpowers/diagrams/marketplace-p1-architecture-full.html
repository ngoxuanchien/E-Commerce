Architecture · 2026-09-28

Marketplace P1 architecture

React SPA and one gateway front three Go services, each with its own Postgres; only the gateway, web, Jaeger UI and MinIO publish host ports.

The boundary is verifiable

  • Published: gateway 8080:8080, web 3000:80, jaeger UI 16686, minio 9000/9001.
  • Internal only: identity, catalog, order, Postgres, Redis, Kafka — and Jaeger's own OTLP 4317.
  • Services trust X-User-Id because the gateway is the only reachable edge.

Per-service data ownership

  • identity_db · catalog_db · order_db — no service reads another's tables.
  • Redis holds the cart hash cart:{user_id}; MinIO holds product-images.
  • Catalog is the inventory single source of truth; every reservation lands in stock_reservations.

Sync vs async paths

  • Sync: gateway HTTP to all three services; order → catalog gRPC GetSkus / ReserveStock / ReleaseStock.
  • Async: order.events, 3 partitions, key order_id; catalog consumes only OrderCancelled.
  • Gateway verifies RS256 against JWKS, cached 5 min; Jaeger OTLP spans gateway → order → catalog.
