Buyer journey, from sign-up to receipt

Six stages, one trough: stock the buyer never sees again move underneath the cart, and a cancellation that returns it asynchronously.

Why checkout is the trough

  • Stock lives in catalog_db and can change between the moment a line enters the cart and the moment checkout reserves it — another buyer is a perfectly ordinary event, not an error.
  • Checkout is all-or-nothing: if any single ReserveStock fails, every order of that checkout is released and marked CANCELLED, and the response is 409 OUT_OF_STOCK with shortages: [{sku_id, requested, available}].
  • So the UI has to name the affected lines and let the buyer fix exactly those. A generic failure here reads as the platform being broken.
  • Everything else in the journey is recoverable; this is the one stage where the buyer can lose the whole basket at once.

The stage-by-stage contract

  • Sign in. Vietnamese UI copy. The access token is kept in memory only; a reload is restored by POST /api/auth/refresh using the HttpOnly refresh_token cookie, so no token ever reaches localStorage.
  • Search. /search?q=&category=&min_price=&max_price=&sort= with keyset cursor pagination and “load more”. "ao thun" finds "Áo thun" — the unaccent extension is wrapped in an IMMUTABLE function so the generated search_vector can index it.
  • Cart. Lines grouped by shop; quantity editable; unavailable lines flagged in place; buying from your own shop is 409; the subtotal counts only available lines.
  • Checkout. COD only, one order per shop, and an Idempotency-Key generated on mount and reused for every retry.

The two frictions, honestly

  • Stock drift at checkout — marked on the map, and the reason the sentiment curve bottoms out here.
  • Asynchronous restock. Cancelling writes OrderCancelled to the outbox; catalog releases the stock when it consumes the event. The user sees CANCELLED first and the stock comes back a moment later — the E2E test polls up to 5 s to see it.
  • Neither is a P1 defect. Both are the direct cost of never overselling and of decoupling the cancellation from the release.
