Five phases, and the one that makes the rest possible

P1 is not a slice of the marketplace — it is the phase that fixes the contracts every later phase depends on. Each phase below is gated on the contract being stable, not on the feature being complete.

P1 is the contract phase

  • Identity, catalog and order contracts freeze here
  • Every later phase builds against the same OpenAPI and proto files
  • A breaking change after P1 is a buf breaking failure, by design

What each phase unlocks

  • P2 seller experience, built on the P1 shop and product contracts
  • P3 payments and fulfillment, built on the P1 order state machine
  • P4 discovery and ranking, built on the P1 Vietnamese search path

Why the ordering is not negotiable

  • A gateway built before identity has nothing to authenticate
  • An order service before the outbox has no way to publish an event
  • Seed and e2e from WS6 gate every phase, not just the last one
