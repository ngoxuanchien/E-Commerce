# WS2 catalog-svc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement catalog-svc: shops, categories, products with SKUs and images, accent-insensitive Vietnamese search, presigned image uploads, and inventory (`GetSkus` / `ReserveStock` / `ReleaseStock` over gRPC plus an `OrderCancelled` Kafka consumer) that never oversells.

**Architecture:** Hexagonal layout inside `services/catalog/internal`: `domain` (entities, validation, cursor, pure rules) ← `app` (use cases behind small port interfaces) ← adapters (`postgres` with sqlc, `httpapi`, `grpcapi`, `storage` for MinIO, `kafka`). Stock correctness lives in Postgres: guarded `UPDATE ... WHERE stock >= q` in one transaction, SKUs locked in sorted order, a per-order transaction advisory lock for idempotency, and `processed_events` for consumer dedupe. Integration tests run against real containers (Postgres, MinIO, Kafka) and an in-process bufconn fake of `IdentityInternal`; every HTTP test response is validated against `api/openapi/catalog.yaml`.

**Tech Stack:** Go 1.27.1, net/http ServeMux, pgx v5 + sqlc v1.31.1 + golang-migrate, Postgres 17 (`unaccent`, `tsvector`, GIN), gRPC + bufconn, minio-go v7, franz-go via `pkg/kafkax`, testcontainers-go v0.44.0, kin-openapi via `pkg/testutil.ContractTransport`, testify.

**Spec:** `docs/superpowers/specs/2026-09-28-marketplace-p1-ws2-catalog.md` (contracts: `docs/superpowers/specs/2026-09-28-marketplace-p1-ws0-foundation.md`; umbrella: `docs/superpowers/specs/2026-09-28-marketplace-p1-overview.md`).

## Global Constraints

- Only modify `services/catalog/` and this plan file. `api/`, `proto/`, `gen/`, `pkg/`, `deploy/`, `go.work*`, `Makefile` and other services are read-only. If a contract or shared lib must change, or `go.work.sum` changes, **stop and report the exact change and why**.
- Module `github.com/ngoxuanchien/e-commerce/services/catalog`, `go 1.27.1`; `pkg`/`gen` required at `v0.0.0` with the existing `replace` directives.
- IDs UUIDv7 (`uuid.NewV7`); timestamps UTC RFC 3339; money `int64` VND; JSON `snake_case`.
- Pagination: `limit` default 20, max 100; `cursor` opaque; response `{ "items": [...], "next_cursor": string|null }`.
- Errors: `{"error":{"code","message","details"}}` via `pkg/httpx`; `VALIDATION_ERROR` details are `{"fields": {"<json path>": "<message>"}}`.
- Shop: `name` 3–80 chars; `slug` matches `^[a-z0-9-]{3,50}$` and is not `me`, `new`, `admin`, `seller`; one shop per user; `GrantRole(user, "seller")` inside the shop-insert transaction with a **3 s** timeout; gRPC failure → rollback, 503 `UPSTREAM_UNAVAILABLE`; user already has a shop / slug taken → 409.
- ProductInput: 1–50 SKUs, at most 9 images, `name` 5–200 chars, `price` 1,000–1,000,000,000, `stock` 0–100,000; `image_keys` must be under `shops/{shop_id}/`; SKU with `id` → update, without → create, existing SKU absent → `active=false` (never deleted); editing `stock` sets on-hand stock; `min_price` = lowest price among active SKUs, same transaction; `DELETE` → `archived`.
- Uploads: only `image/jpeg|png|webp`; presigned POST, max 5 MB, exact content type, key `shops/{shop_id}/{uuid}.{ext}`, expires in 10 min; public URL = `PUBLIC_ASSET_BASE_URL/{object_key}`.
- Browse: only `active` products with ≥ 1 active SKU; `q` → `websearch_to_tsquery('simple', vn_unaccent(q))`; default sort `relevance` with `q`, else `newest`; `category` slug includes children; keyset cursor = base64 JSON `{sort_value, id}`; non-active product detail → 404 except for its shop owner.
- gRPC: `GetSkus` max 100 ids, unknown SKUs omitted; `ReserveStock` idempotent per `order_id`, merge duplicates, sort by `sku_id`, all-or-nothing, shortage → `FAILED_PRECONDITION` + `InsufficientStock{shortages[sku_id, requested, available]}`; `ReleaseStock` idempotent, no rows → OK.
- Kafka: topic `order.events`, group `catalog-svc`; only `OrderCancelled` → release + insert into `processed_events` in the same transaction; other types ignored; failures retried; offsets committed only after success (`pkg/kafkax` does this).
- Env: `SERVICE_NAME`, `HTTP_ADDR`, `GRPC_ADDR`, `DATABASE_URL`, `KAFKA_BROKERS`, `OTEL_EXPORTER_OTLP_ENDPOINT`, `LOG_LEVEL`, `IDENTITY_GRPC_ADDR`, `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET=product-images`, `PUBLIC_ASSET_BASE_URL`.
- `/readyz` checks Postgres, MinIO and Kafka.
- Tests run with `-race`; concurrency/idempotency tests must pass with `-count=5`.
- All code, comments, docs and commit messages in English. Commit style: `feat(catalog): ...`, `test(catalog): ...`, `docs(catalog): ...`.

## Review Focus

1. **A retried `ReserveStock` racing itself** (same `order_id`, concurrent calls): stock is decremented exactly once, never twice → test in Task 8 (`TestReserveStockSameOrderConcurrently`).
2. **Search text with tsquery syntax, punctuation or SQL** (`"`, `-`, `or`, `!!!`, `'; drop table products; --`): 200 with a (possibly empty) page, never 500 → tests in Task 5 and Task 10.
3. **`đ`/`Đ` and upper case**: `dam` finds `Đầm maxi`, `AO THUN` finds `Áo thun` → test in Task 5.
4. **PATCH with a SKU id that belongs to another product/shop**: 400 on `skus[i].id` and neither product changes → tests in Task 4 and Task 11.
5. **Malformed paging/filter params** (`limit=0|101|abc`, garbage cursor, cursor from another sort, `min_price > max_price`, unknown `sort`): 400 `VALIDATION_ERROR` naming the field, never 500 → tests in Tasks 2, 5 and 10.

## Decisions (gaps in the spec resolved here; mirrored in `services/catalog/README.md`)

1. Adapter packages are `internal/adapter/httpapi` and `internal/adapter/grpcapi` (not `http`/`grpc`) so they don't shadow `net/http` and `google.golang.org/grpc`.
2. `shops.description` and `products.description` are `NOT NULL DEFAULT ''` because the contract always returns a string.
3. Extra caps not in the contract: shop description ≤ 2,000 chars, product description ≤ 5,000, SKU name 1–100; names/descriptions are trimmed.
4. `image_keys` must match `shops/{shop_id}/{uuid}.{jpg|png|webp}` exactly (stricter than a prefix check; blocks `../`), no duplicates. Object existence in MinIO is not checked.
5. `ReserveStock` treats unknown or inactive SKUs (or inactive products) as shortages with `available = 0` (`FAILED_PRECONDITION`), so order-svc maps them to `OUT_OF_STOCK`; malformed ids / non-positive quantities → `INVALID_ARGUMENT`. `GetSkus` omits malformed ids like unknown ones; > 100 ids → `INVALID_ARGUMENT`.
6. `ReserveStock`/`ReleaseStock`/consumer release take `pg_advisory_xact_lock(hashtextextended(order_id, 0))` first, so concurrent calls for one order serialize; the "already reserved?" check is then race-free.
7. Known limitation: a `ReleaseStock` that arrives *before* the first `ReserveStock` of the same order leaves no tombstone, so a later reserve still reserves. order-svc's sweeper covers this (WS3 §3).
8. Cursor JSON also carries `sort`; a cursor used with a different sort → 400 on `cursor`.
9. `sort=relevance` without `q` falls back to `newest`.
10. Public product detail hides inactive SKUs; the shop owner sees all SKUs and non-active products.
11. `upload_url` = `PUBLIC_ASSET_BASE_URL` (the path-style bucket URL), because `MINIO_ENDPOINT` is the in-cluster address; a POST-policy signature does not cover the host. Bucket CORS for browser uploads is a deploy concern (WS6).
12. A caller with role `seller` but no shop gets 403 `FORBIDDEN` ("open a shop first") on `/api/seller/*`, and 404 on `/api/shops/me`.
13. A non-UUID `X-User-Id` is treated as unauthenticated (401) on authenticated routes and as anonymous on public ones.
14. Kafka: undecodable, unsupported-version, malformed or non-`OrderCancelled` records are logged and skipped (a poison record must not block its partition); database errors are returned and retried by `kafkax`.
15. If `GrantRole` succeeds but the commit fails, the user keeps the seller role without a shop; retrying works because `GrantRole` is idempotent.
16. `/readyz` Kafka check = `kafkax.Producer.Ping`; MinIO check = `BucketExists(MINIO_BUCKET)`.
17. Tests: one Postgres container per test binary (`TestMain`), each test gets a fresh database cloned from a migrated template (`CREATE DATABASE ... TEMPLATE`).

`services/catalog/migrations/000002_catalog_schema.up.sql`:
```sql
-- Catalog schema (WS2 §2).
CREATE EXTENSION IF NOT EXISTS unaccent;

-- unaccent() is STABLE because its dictionary can change; generated columns
-- and indexes need IMMUTABLE, so wrap it with the dictionary pinned.
CREATE FUNCTION vn_unaccent(text) RETURNS text
    LANGUAGE sql IMMUTABLE PARALLEL SAFE STRICT
    AS $$ SELECT public.unaccent('public.unaccent'::regdictionary, $1) $$;

CREATE TABLE shops (
    id            uuid PRIMARY KEY,
    owner_user_id uuid NOT NULL,
    name          text NOT NULL,
    slug          text NOT NULL,
    description   text NOT NULL DEFAULT '',
    created_at    timestamptz NOT NULL DEFAULT now(),
    updated_at    timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT shops_owner_user_id_key UNIQUE (owner_user_id), -- P1: one shop per user
    CONSTRAINT shops_slug_key UNIQUE (slug)
);

CREATE TABLE categories (
    id        uuid PRIMARY KEY,
    parent_id uuid REFERENCES categories (id),
    name      text NOT NULL,
    slug      text NOT NULL UNIQUE,
    position  int  NOT NULL DEFAULT 0
);

CREATE TABLE products (
    id            uuid PRIMARY KEY,
    shop_id       uuid NOT NULL REFERENCES shops (id),
    category_id   uuid NOT NULL,
    name          text NOT NULL,
    description   text NOT NULL DEFAULT '',
    status        text NOT NULL CHECK (status IN ('draft', 'active', 'archived')),
    min_price     bigint, -- lowest price among active SKUs; NULL when none is active
    search_vector tsvector GENERATED ALWAYS AS (
        setweight(to_tsvector('simple', vn_unaccent(name)), 'A') ||
        setweight(to_tsvector('simple', vn_unaccent(description)), 'B')
    ) STORED,
    created_at    timestamptz NOT NULL DEFAULT now(),
    updated_at    timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT products_category_id_fkey FOREIGN KEY (category_id) REFERENCES categories (id)
);
CREATE INDEX products_search_vector_idx ON products USING gin (search_vector);
CREATE INDEX products_status_created_idx ON products (status, created_at DESC, id);
CREATE INDEX products_status_min_price_idx ON products (status, min_price, id);
CREATE INDEX products_shop_id_idx ON products (shop_id);
CREATE INDEX products_category_id_idx ON products (category_id);

CREATE TABLE product_images (
    id         uuid PRIMARY KEY,
    product_id uuid NOT NULL REFERENCES products (id) ON DELETE CASCADE,
    object_key text NOT NULL,
    position   int  NOT NULL
);
CREATE INDEX product_images_product_idx ON product_images (product_id, position);

CREATE TABLE skus (
    id         uuid PRIMARY KEY,
    product_id uuid NOT NULL REFERENCES products (id),
    name       text   NOT NULL,
    price      bigint NOT NULL CHECK (price > 0),
    stock      int    NOT NULL CHECK (stock >= 0), -- last line of defence against overselling
    active     boolean NOT NULL DEFAULT true,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX skus_product_id_idx ON skus (product_id);

CREATE TABLE stock_reservations (
    order_id   uuid NOT NULL,
    sku_id     uuid NOT NULL REFERENCES skus (id),
    quantity   int  NOT NULL CHECK (quantity > 0),
    status     text NOT NULL CHECK (status IN ('reserved', 'released')),
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    PRIMARY KEY (order_id, sku_id)
);

CREATE TABLE processed_events (
    event_id     uuid PRIMARY KEY,
    processed_at timestamptz NOT NULL DEFAULT now()
);
```

```go
	templateURL *url.URL   // DSN of the migrated template database; nil when Postgres is not running
	createMu    sync.Mutex // serializes CREATE DATABASE ... TEMPLATE

// RunWithPostgres is a TestMain body: unless -short, it starts Postgres,
// migrates a template database, runs the tests and removes the container.
//
//	func TestMain(m *testing.M) { os.Exit(testsupport.RunWithPostgres(m)) }
func RunWithPostgres(m *testing.M) int {
	flag.Parse()
	if testing.Short() {
		return m.Run()
	}
	ctx := context.Background()
	c, err := tcpostgres.Run(ctx, testutil.PostgresImage,
		tcpostgres.WithDatabase(templateDB), tcpostgres.WithUsername("test"), tcpostgres.WithPassword("test"),
		tcpostgres.BasicWaitStrategies())
	defer func() { _ = testcontainers.TerminateContainer(c) }()
	if err != nil {
		fmt.Fprintln(os.Stderr, "start postgres:", err)
		return 1
	}
	dsn, err := c.ConnectionString(ctx, "sslmode=disable")
	if err != nil {
		fmt.Fprintln(os.Stderr, "postgres dsn:", err)
		return 1
	}
	if err := pgxx.Migrate(dsn, migrations.FS); err != nil {
		fmt.Fprintln(os.Stderr, "migrate template:", err)
		return 1
	}
	if templateURL, err = url.Parse(dsn); err != nil {
		fmt.Fprintln(os.Stderr, "parse dsn:", err)
		return 1
	}
	return m.Run()
}

// DB returns a pool on a new database cloned from the migrated template; the
// database is dropped when the test ends. Skips when Postgres is not running.
func DB(t testing.TB) *pgxpool.Pool {
	t.Helper()
	if templateURL == nil {
		t.Skip("postgres is not running (-short, or the package lacks TestMain calling RunWithPostgres)")
	}
	ctx := context.Background()
	name := "t_" + strings.ReplaceAll(uuid.NewString(), "-", "")

	createMu.Lock()
	err := adminExec(ctx, "CREATE DATABASE "+name+" TEMPLATE "+templateDB)
	createMu.Unlock()
	if err != nil {
		t.Fatalf("create test database: %v", err)
	}
	pool, err := pgxx.NewPool(ctx, dsnFor(name))
	if err != nil {
		t.Fatalf("connect test database: %v", err)
	}
	t.Cleanup(func() {
		pool.Close()
		_ = adminExec(context.Background(), "DROP DATABASE IF EXISTS "+name+" WITH (FORCE)")
	})
	return pool
}

func adminExec(ctx context.Context, sql string) error {
	conn, err := pgx.Connect(ctx, dsnFor("postgres"))
	if err != nil {
		return err
	}
	defer func() { _ = conn.Close(ctx) }()
	_, err = conn.Exec(ctx, sql)
	return err
}

func dsnFor(db string) string {
	u := *templateURL
	u.Path = "/" + db
	return u.String()
}
```

```go
import (
	"errors"
	"fmt"
	"sort"
	"strings"
	"unicode/utf8"
)

var (
	// ErrNotFound means the resource does not exist or is not visible to the caller.
	ErrNotFound = errors.New("not found")
	// ErrNoShop means a seller operation was attempted by a user without a shop.
	ErrNoShop = errors.New("caller has no shop")
	// ErrUpstreamUnavailable means a dependency (identity-svc) failed or timed out.
	ErrUpstreamUnavailable = errors.New("upstream unavailable")
)

// ValidationError maps JSON field paths (e.g. "skus[0].price") to messages.
type ValidationError struct {
	Fields map[string]string
}

func (e *ValidationError) Error() string {
	keys := make([]string, 0, len(e.Fields))
	for k := range e.Fields {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	parts := make([]string, len(keys))
	for i, k := range keys {
		parts[i] = k + " " + e.Fields[k]
	}
	return "validation failed: " + strings.Join(parts, "; ")
}

// ConflictError is a uniqueness conflict whose message is safe to show to clients.
type ConflictError struct {
	Message string
}

func (e *ConflictError) Error() string { return e.Message }

const (
	msgRequired = "is required"
	msgUUID     = "must be a valid UUID"
)

// fieldErrors collects the first message per field.
type fieldErrors map[string]string

func (f fieldErrors) add(field, msg string) {
	if _, ok := f[field]; !ok {
		f[field] = msg
	}
}

func (f fieldErrors) err() error {
	if len(f) == 0 {
		return nil
	}
	return &ValidationError{Fields: f}
}

// checkChars validates the rune length of s against [minLen, maxLen].
func checkChars(f fieldErrors, field, s string, minLen, maxLen int) {
	switch n := utf8.RuneCountInString(s); {
	case n == 0 && minLen > 0:
		f.add(field, msgRequired)
	case n < minLen:
		f.add(field, fmt.Sprintf("must be at least %d characters", minLen))
	case n > maxLen:
		f.add(field, fmt.Sprintf("must be at most %d characters", maxLen))
	}
}
```

```go
// Shop is a seller's storefront. P1: at most one per user.
type Shop struct {
	ID          uuid.UUID
	OwnerUserID uuid.UUID
	Name        string
	Slug        string
	Description string
	CreatedAt   time.Time
	UpdatedAt   time.Time
}

type ShopRef struct {
	ID   uuid.UUID
	Name string
	Slug string
}

const (
	minShopName        = 3
	maxShopName        = 80
	maxShopDescription = 2000
)

var (
	slugPattern = regexp.MustCompile(`^[a-z0-9-]{3,50}$`)
	// Reserved so /api/shops/me etc. never collide with /api/shops/{slug}.
	reservedSlugs = map[string]bool{"me": true, "new": true, "admin": true, "seller": true}
)

// ShopInput is the payload for opening a shop.
type ShopInput struct {
	Name        string
	Slug        string
	Description string
}

// Validate trims the input and checks WS2 §3 rules.
func (in ShopInput) Validate() (ShopInput, error) {
	in.Name = strings.TrimSpace(in.Name)
	in.Description = strings.TrimSpace(in.Description)
	f := fieldErrors{}
	checkChars(f, "name", in.Name, minShopName, maxShopName)
	switch {
	case !slugPattern.MatchString(in.Slug):
		f.add("slug", "must match ^[a-z0-9-]{3,50}$")
	case reservedSlugs[in.Slug]:
		f.add("slug", "is reserved")
	}
	checkChars(f, "description", in.Description, 0, maxShopDescription)
	return in, f.err()
}

// ShopPatch updates name and/or description; the slug is immutable.
type ShopPatch struct {
	Name        *string
	Description *string
}

// Validate trims the patch and requires at least one field.
func (p ShopPatch) Validate() (ShopPatch, error) {
	f := fieldErrors{}
	if p.Name == nil && p.Description == nil {
		f.add("body", "must contain at least one field")
	}
	if p.Name != nil {
		name := strings.TrimSpace(*p.Name)
		checkChars(f, "name", name, minShopName, maxShopName)
		p.Name = &name
	}
	if p.Description != nil {
		d := strings.TrimSpace(*p.Description)
		checkChars(f, "description", d, 0, maxShopDescription)
		p.Description = &d
	}
	return p, f.err()
}
```

```go
	StatusArchived ProductStatus = "archived"

	return "", false

var imageKeyPattern = regexp.MustCompile(`^shops/([0-9a-f-]{36})/[0-9a-f-]{36}\.(jpg|png|webp)$`)

// ProductInput is a raw seller request (create or partial update). Nil

// SetImages/SetSkus say whether the lists replace the current ones.
type ProductChange struct {

	Name        *string
	Description *string
	Status      *ProductStatus
	SetImages   bool
	ImageKeys   []string
	SetSkus     bool

// Validate checks in for a product of shopID. create requires category_id,
// name, status and skus and forbids SKU ids; an update needs at least one field.
func (in ProductInput) Validate(shopID uuid.UUID, create bool) (ProductChange, error) {
	f := fieldErrors{}
	var c ProductChange
	if !create && in.CategoryID == nil && in.Name == nil && in.Description == nil &&
		in.Status == nil && in.ImageKeys == nil && in.Skus == nil {
		f.add("body", "must contain at least one field")
	}
	if create {
		for field, missing := range map[string]bool{
			"category_id": in.CategoryID == nil, "name": in.Name == nil,
			"status": in.Status == nil, "skus": in.Skus == nil,
		} {
			if missing {
				f.add(field, msgRequired)
			}
		}
	}
	if in.CategoryID != nil {
		if id, err := uuid.Parse(*in.CategoryID); err != nil {
			f.add("category_id", msgUUID)
		} else {
			c.CategoryID = &id
		}
	}
	if in.Name != nil {
		name := strings.TrimSpace(*in.Name)
		checkChars(f, "name", name, MinProductName, MaxProductName)
		c.Name = &name
	}
	if in.Description != nil {
		d := strings.TrimSpace(*in.Description)
		checkChars(f, "description", d, 0, MaxDescription)
		c.Description = &d
	}
	if in.Status != nil {
		if st, ok := ParseProductStatus(*in.Status); ok {
			c.Status = &st
		} else {
			f.add("status", "must be one of: draft active archived")
		}
	}
	if in.ImageKeys != nil {
		c.SetImages = true
		c.ImageKeys = validateImageKeys(f, shopID, in.ImageKeys)
	}
	if in.Skus != nil {
		c.SetSkus = true
		c.Skus = validateSkus(f, in.Skus, create)
	}
	return c, f.err()
}

func validateImageKeys(f fieldErrors, shopID uuid.UUID, keys []string) []string {
	if len(keys) > MaxImages {
		f.add("image_keys", fmt.Sprintf("must have at most %d items", MaxImages))
		return nil
	}
	seen := make(map[string]bool, len(keys))
	for i, k := range keys {
		field := fmt.Sprintf("image_keys[%d]", i)
		m := imageKeyPattern.FindStringSubmatch(k)
		switch {
		case m == nil || m[1] != shopID.String():
			f.add(field, "must be an image uploaded by this shop")
		case seen[k]:
			f.add(field, "is duplicated")
		}
		seen[k] = true
	}
	return append([]string{}, keys...)
}

func validateSkus(f fieldErrors, in []SkuInput, create bool) []SkuChange {
	switch {
	case len(in) < MinSkus:
		f.add("skus", fmt.Sprintf("must have at least %d item", MinSkus))
		return nil
	case len(in) > MaxSkus:
		f.add("skus", fmt.Sprintf("must have at most %d items", MaxSkus))
		return nil
	}
	out := make([]SkuChange, len(in))
	seen := make(map[uuid.UUID]bool, len(in))
	for i, s := range in {
		p := fmt.Sprintf("skus[%d]", i)
		c := SkuChange{Name: strings.TrimSpace(s.Name), Active: true}
		if s.ID != nil {

			case create:
```

```go
	case n < 1 || n > MaxPageLimit:

	Cursor       string
```

```go
package domain

import (
	"encoding/base64"
	"encoding/json"
	"fmt"

	"github.com/google/uuid"

// Cursor is a keyset position: the sort key and id of the last item returned.
// It is encoded as base64url JSON {"sort", "sort_value", "id"}.
type Cursor struct {
	Sort  string          `json:"sort"`
	Value json.RawMessage `json:"sort_value"`
	ID    uuid.UUID       `json:"id"`
}

// EncodeCursor builds the opaque cursor for the item (value, id) under sort.
func EncodeCursor(sort string, value any, id uuid.UUID) (string, error) {
	v, err := json.Marshal(value)
	if err != nil {
		return "", fmt.Errorf("encode cursor value: %w", err)
	}
	b, err := json.Marshal(Cursor{Sort: sort, Value: v, ID: id})
	if err != nil {
		return "", fmt.Errorf("encode cursor: %w", err)
	}
	return base64.RawURLEncoding.EncodeToString(b), nil
}

// DecodeCursor parses raw; "" yields (nil, nil). A malformed cursor or one
// produced for another sort is a validation error on "cursor".
func DecodeCursor(raw, sort string) (*Cursor, error) {
	if raw == "" {
		return nil, nil
	}
	b, err := base64.RawURLEncoding.DecodeString(raw)
	if err != nil {
		return nil, invalidCursor()
	}
	var c Cursor
	if err := json.Unmarshal(b, &c); err != nil || c.Sort != sort || c.ID == uuid.Nil || len(c.Value) == 0 {
		return nil, invalidCursor()
	}
	return &c, nil
}

// DecodeValue unmarshals the sort value into dst.
func (c *Cursor) DecodeValue(dst any) error {
	if err := json.Unmarshal(c.Value, dst); err != nil {
		return invalidCursor()
	}
	return nil
}

func invalidCursor() error {
	return &ValidationError{Fields: map[string]string{"cursor": "is invalid"}}
}
```

```go
	Quantity int32
}

// StockShortage describes one SKU that could not be reserved.
type StockShortage struct {
	SkuID     uuid.UUID
	Requested int32
	Available int32
}

// InsufficientStockError lists every shortage of a failed reservation.
type InsufficientStockError struct {
	Shortages []StockShortage
}

func (e *InsufficientStockError) Error() string {
	return fmt.Sprintf("insufficient stock for %d sku(s)", len(e.Shortages))
}

// NormalizeStockItems merges duplicate SKUs and sorts by SKU id, the lock
// order every stock transaction uses to avoid deadlocks.
func NormalizeStockItems(items []StockItem) ([]StockItem, error) {
	f := fieldErrors{}
	switch {
	case len(items) == 0:
		f.add("items", msgRequired)
		return nil, f.err()
	case len(items) > MaxStockItems:
		f.add("items", fmt.Sprintf("must have at most %d items", MaxStockItems))
		return nil, f.err()
	}
	sums := make(map[uuid.UUID]int64, len(items))
	for i, it := range items {
		if it.Quantity <= 0 {
			f.add(fmt.Sprintf("items[%d].quantity", i), "must be at least 1")
			continue
		}
		sums[it.SkuID] += int64(it.Quantity)
	}
	out := make([]StockItem, 0, len(sums))
	for id, q := range sums {
		if q > math.MaxInt32 {
			f.add("items", "total quantity of sku "+id.String()+" is too large")
			continue
		}
		out = append(out, StockItem{SkuID: id, Quantity: int32(q)})
	}
	if err := f.err(); err != nil {
		return nil, err
	}
	slices.SortFunc(out, func(a, b StockItem) int { return bytes.Compare(a.SkuID[:], b.SkuID[:]) })
	return out, nil
}
```

```go
// sqlc-generated queries (see queries/) plus a hand-built search query.
package postgres

import (
	"context"
	"errors"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgconn"
	"github.com/jackc/pgx/v5/pgxpool"

	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/adapter/postgres/sqlcdb"
	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/domain"
)

// Constraint names from migrations/000002_catalog_schema.up.sql.
const (
	constraintShopOwner       = "shops_owner_user_id_key"
	constraintShopSlug        = "shops_slug_key"
	constraintProductCategory = "products_category_id_fkey"
)

// Store is the catalog repository.
type Store struct {
	pool *pgxpool.Pool
	q    *sqlcdb.Queries
}

// New returns a Store backed by pool.
func New(pool *pgxpool.Pool) *Store {
	return &Store{pool: pool, q: sqlcdb.New(pool)}
}

// Ping checks database connectivity (readiness).
func (s *Store) Ping(ctx context.Context) error { return s.pool.Ping(ctx) }

func newID() uuid.UUID { return uuid.Must(uuid.NewV7()) }

// notFound maps pgx.ErrNoRows to domain.ErrNotFound.
func notFound(err error) error {
	if errors.Is(err, pgx.ErrNoRows) {
		return domain.ErrNotFound
	}
	return err
}

// constraintOf returns the violated constraint name, or "".
func constraintOf(err error) string {
	var pe *pgconn.PgError
	if errors.As(err, &pe) {
		return pe.ConstraintName
	}
	return ""
}
```

```go
package postgres

import (
	"context"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"

	"github.com/ngoxuanchien/e-commerce/pkg/pgxx"
	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/adapter/postgres/sqlcdb"
	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/domain"
)

// CreateShop inserts shop and runs beforeCommit in the same transaction; an
// error from beforeCommit rolls the insert back and is returned unchanged.
func (s *Store) CreateShop(ctx context.Context, shop domain.Shop, beforeCommit func(context.Context) error) (domain.Shop, error) {
	var out domain.Shop
	err := pgxx.WithTx(ctx, s.pool, func(tx pgx.Tx) error {
		row, err := s.q.WithTx(tx).InsertShop(ctx, sqlcdb.InsertShopParams{
			ID: shop.ID, OwnerUserID: shop.OwnerUserID, Name: shop.Name, Slug: shop.Slug, Description: shop.Description,
		})
		switch constraintOf(err) {
		case constraintShopOwner:
			return &domain.ConflictError{Message: "you already have a shop"}
		case constraintShopSlug:
			return &domain.ConflictError{Message: "shop slug is already taken"}
		}
		if err != nil {
			return err
		}
		out = toShop(row)
		return beforeCommit(ctx)
	})
	if err != nil {
		return domain.Shop{}, err
	}
	return out, nil
}

// ShopByOwner returns the shop owned by owner.
func (s *Store) ShopByOwner(ctx context.Context, owner uuid.UUID) (domain.Shop, error) {
	row, err := s.q.GetShopByOwner(ctx, owner)
	if err != nil {
		return domain.Shop{}, notFound(err)
	}
	return toShop(row), nil
}

// ShopBySlug returns the shop with slug.
func (s *Store) ShopBySlug(ctx context.Context, slug string) (domain.Shop, error) {
	row, err := s.q.GetShopBySlug(ctx, slug)
	if err != nil {
		return domain.Shop{}, notFound(err)
	}
	return toShop(row), nil
}

// UpdateShop applies p to the shop owned by owner.
func (s *Store) UpdateShop(ctx context.Context, owner uuid.UUID, p domain.ShopPatch) (domain.Shop, error) {
	row, err := s.q.UpdateShop(ctx, sqlcdb.UpdateShopParams{Name: p.Name, Description: p.Description, OwnerUserID: owner})
	if err != nil {
		return domain.Shop{}, notFound(err)
	}
	return toShop(row), nil
}

func toShop(r sqlcdb.Shop) domain.Shop {
	return domain.Shop{
		ID: r.ID, OwnerUserID: r.OwnerUserID, Name: r.Name, Slug: r.Slug, Description: r.Description,
		CreatedAt: r.CreatedAt, UpdatedAt: r.UpdatedAt,
	}
```

```go
func (s *Store) Categories(ctx context.Context) ([]domain.Category, error) {
	rows, err := s.q.ListCategories(ctx)
	if err != nil {
		return nil, err
	}
	tops := []domain.Category{}
	index := map[uuid.UUID]int{}
	for _, r := range rows {
		if r.ParentID == nil {
			index[r.ID] = len(tops)
			tops = append(tops, domain.Category{ID: r.ID, Name: r.Name, Slug: r.Slug, Children: []domain.Category{}})
		}
	}
	for _, r := range rows {
		if r.ParentID == nil {
			continue
		}

			tops[i].Children = append(tops[i].Children,
				domain.Category{ID: r.ID, Name: r.Name, Slug: r.Slug, Children: []domain.Category{}})
		}
	}
```

```sql
-- name: InsertProduct :exec
INSERT INTO products (id, shop_id, category_id, name, description, status)
VALUES ($1, $2, $3, $4, $5, $6);

-- name: LockShopProduct :one
SELECT id FROM products WHERE id = $1 AND shop_id = $2 FOR UPDATE;

-- name: UpdateProductFields :exec
UPDATE products SET
    category_id = coalesce(sqlc.narg('category_id'), category_id),
    name        = coalesce(sqlc.narg('name'), name),
    description = coalesce(sqlc.narg('description'), description),
    status      = coalesce(sqlc.narg('status'), status),
    updated_at  = now()
WHERE id = sqlc.arg('id');

-- name: SetMinPrice :exec
UPDATE products SET min_price = $2 WHERE id = $1;

-- name: ArchiveProduct :execrows
UPDATE products SET status = 'archived', updated_at = now()
WHERE id = $1 AND shop_id = $2;

-- name: DeleteProductImages :exec
DELETE FROM product_images WHERE product_id = $1;

-- name: InsertProductImage :exec
INSERT INTO product_images (id, product_id, object_key, position) VALUES ($1, $2, $3, $4);

-- name: ListProductSkus :many
SELECT id, name, price, stock, active FROM skus WHERE product_id = $1 ORDER BY created_at, id;

-- name: InsertSku :exec
INSERT INTO skus (id, product_id, name, price, stock, active) VALUES ($1, $2, $3, $4, $5, $6);

-- name: UpdateSku :exec
UPDATE skus SET name = $3, price = $4, stock = $5, active = $6, updated_at = now()
WHERE id = $1 AND product_id = $2;

-- name: DeactivateSku :exec
UPDATE skus SET active = false, updated_at = now() WHERE id = $1 AND active;

-- name: GetProducts :many
SELECT p.id, p.shop_id, p.category_id, p.name, p.description, p.status, p.min_price,
       p.created_at, p.updated_at, s.name AS shop_name, s.slug AS shop_slug, s.owner_user_id
FROM products p JOIN shops s ON s.id = p.shop_id
WHERE p.id = ANY(sqlc.arg('ids')::uuid[]);

-- name: GetProductsSkus :many
SELECT id, product_id, name, price, stock, active FROM skus
WHERE product_id = ANY(sqlc.arg('ids')::uuid[])
ORDER BY created_at, id;

-- name: GetProductsImages :many
SELECT product_id, object_key FROM product_images
WHERE product_id = ANY(sqlc.arg('ids')::uuid[])
ORDER BY position;

-- name: ListShopProductIDs :many
SELECT id, created_at FROM products
WHERE shop_id = sqlc.arg('shop_id')
  AND (sqlc.narg('status')::text IS NULL OR status = sqlc.narg('status')::text)
  AND (sqlc.narg('after_created_at')::timestamptz IS NULL
       OR (created_at, id) < (sqlc.narg('after_created_at')::timestamptz, sqlc.narg('after_id')::uuid))
ORDER BY created_at DESC, id DESC
LIMIT sqlc.arg('max_rows');
```

```go
func TestUpdateProductSkuSemantics(t *testing.T) {
	store := postgres.New(testsupport.DB(t))
	shop := openShop(t, store)
	p := createProduct(t, store, shop.ID, activeChange("Áo thun cotton", 150_000, 120_000))
	a, b := p.Skus[0], p.Skus[1]

	err := store.UpdateProduct(context.Background(), shop.ID, p.ID, domain.ProductChange{
		SetSkus: true,
		Skus: []domain.SkuChange{
			{ID: &a.ID, Name: "Size M", Price: 200_000, Stock: 3, Active: true}, // update; stock set directly
			{Name: "Size XL", Price: 180_000, Stock: 5, Active: true},           // create
		}, // b omitted → deactivated, not deleted

	got := getProduct(t, store, p.ID)

	require.NotNil(t, got.MinPrice)
```

```go
package postgres

import (
	"context"
	"fmt"
	"time"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"

	"github.com/ngoxuanchien/e-commerce/pkg/pgxx"
	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/adapter/postgres/sqlcdb"
	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/domain"
)

// sellerListSort names the cursor sort of ListShopProducts.
const sellerListSort = "newest"

// CreateProduct inserts a product of shopID from a validated create change.
func (s *Store) CreateProduct(ctx context.Context, shopID uuid.UUID, c domain.ProductChange) (uuid.UUID, error) {
	id := newID()
	err := pgxx.WithTx(ctx, s.pool, func(tx pgx.Tx) error {
		q := s.q.WithTx(tx)
		err := q.InsertProduct(ctx, sqlcdb.InsertProductParams{
			ID: id, ShopID: shopID, CategoryID: *c.CategoryID, Name: *c.Name,
			Description: deref(c.Description), Status: string(*c.Status),
		})
		if err != nil {
			return categoryError(err)
		}
		return applyChildren(ctx, q, id, c)
	})
	if err != nil {
		return uuid.Nil, err
	}
	return id, nil
}

// UpdateProduct applies c to productID if it belongs to shopID.
func (s *Store) UpdateProduct(ctx context.Context, shopID, productID uuid.UUID, c domain.ProductChange) error {
	return pgxx.WithTx(ctx, s.pool, func(tx pgx.Tx) error {
		q := s.q.WithTx(tx)
		if _, err := q.LockShopProduct(ctx, sqlcdb.LockShopProductParams{ID: productID, ShopID: shopID}); err != nil {
			return notFound(err)
		}
		err := q.UpdateProductFields(ctx, sqlcdb.UpdateProductFieldsParams{
			CategoryID: c.CategoryID, Name: c.Name, Description: c.Description,
			Status: (*string)(c.Status), ID: productID,
		})
		if err != nil {
			return categoryError(err)
		}
		return applyChildren(ctx, q, productID, c)
	})
}

// ArchiveProduct sets status=archived on productID if it belongs to shopID.
func (s *Store) ArchiveProduct(ctx context.Context, shopID, productID uuid.UUID) error {
	n, err := s.q.ArchiveProduct(ctx, sqlcdb.ArchiveProductParams{ID: productID, ShopID: shopID})
	if err != nil {
		return err
	}
	if n == 0 {
		return domain.ErrNotFound
	}
	return nil
}

// applyChildren replaces images and applies SKU changes when set, then
// recomputes min_price, all inside the caller's transaction.
func applyChildren(ctx context.Context, q *sqlcdb.Queries, productID uuid.UUID, c domain.ProductChange) error {
	if c.SetImages {
		if err := q.DeleteProductImages(ctx, productID); err != nil {
			return err
		}
		for i, key := range c.ImageKeys {
			if err := q.InsertProductImage(ctx, sqlcdb.InsertProductImageParams{
				ID: newID(), ProductID: productID, ObjectKey: key, Position: int32(i),
			}); err != nil {
				return err
			}
		}
	}
	skus, err := q.ListProductSkus(ctx, productID)
	if err != nil {
		return err
	}
	if c.SetSkus {
		if err := applySkus(ctx, q, productID, skus, c.Skus); err != nil {
			return err
		}
		if skus, err = q.ListProductSkus(ctx, productID); err != nil {
			return err
		}
	}
	current := make([]domain.Sku, len(skus))
	for i, r := range skus {
		current[i] = domain.Sku{ID: r.ID, Name: r.Name, Price: r.Price, Stock: r.Stock, Active: r.Active}
	}
	return q.SetMinPrice(ctx, sqlcdb.SetMinPriceParams{ID: productID, MinPrice: domain.MinActivePrice(current)})
}

// applySkus updates SKUs with an id, creates those without, and deactivates
// existing SKUs missing from in (they are never deleted).
func applySkus(ctx context.Context, q *sqlcdb.Queries, productID uuid.UUID, existing []sqlcdb.ListProductSkusRow, in []domain.SkuChange) error {
	owned := make(map[uuid.UUID]bool, len(existing))
	for _, s := range existing {
		owned[s.ID] = true
	}
	keep := make(map[uuid.UUID]bool, len(in))
	for i, sku := range in {
		if sku.ID == nil {
			if err := q.InsertSku(ctx, sqlcdb.InsertSkuParams{
				ID: newID(), ProductID: productID, Name: sku.Name, Price: sku.Price, Stock: sku.Stock, Active: sku.Active,
			}); err != nil {
				return err
			}
			continue
		}
		if !owned[*sku.ID] {
			return &domain.ValidationError{Fields: map[string]string{
				fmt.Sprintf("skus[%d].id", i): "does not belong to this product",
			}}
		}
		keep[*sku.ID] = true
		if err := q.UpdateSku(ctx, sqlcdb.UpdateSkuParams{
			ID: *sku.ID, ProductID: productID, Name: sku.Name, Price: sku.Price, Stock: sku.Stock, Active: sku.Active,
		}); err != nil {
			return err
		}
	}
	for _, s := range existing {
		if !keep[s.ID] && s.Active {
			if err := q.DeactivateSku(ctx, s.ID); err != nil {
				return err
			}
		}
	}
	return nil
}

// Products loads full products (with SKUs and images) in the order of ids,
// skipping unknown ids.
func (s *Store) Products(ctx context.Context, ids []uuid.UUID) ([]domain.Product, error) {
	if len(ids) == 0 {
		return []domain.Product{}, nil
	}
	rows, err := s.q.GetProducts(ctx, ids)
	if err != nil {
		return nil, err
	}
	skus, err := s.q.GetProductsSkus(ctx, ids)
	if err != nil {
		return nil, err
	}
	images, err := s.q.GetProductsImages(ctx, ids)
	if err != nil {
		return nil, err
	}
	byID := make(map[uuid.UUID]*domain.Product, len(rows))
	for _, r := range rows {
		byID[r.ID] = &domain.Product{
			ID:          r.ID,
			Shop:        domain.ShopRef{ID: r.ShopID, Name: r.ShopName, Slug: r.ShopSlug},
			OwnerUserID: r.OwnerUserID,
			CategoryID:  r.CategoryID,
			Name:        r.Name,
			Description: r.Description,
			Status:      domain.ProductStatus(r.Status),
			ImageKeys:   []string{},
			Skus:        []domain.Sku{},
			MinPrice:    r.MinPrice,
			CreatedAt:   r.CreatedAt,
			UpdatedAt:   r.UpdatedAt,
		}
	}
	for _, r := range skus {
		if p := byID[r.ProductID]; p != nil {
			p.Skus = append(p.Skus, domain.Sku{ID: r.ID, Name: r.Name, Price: r.Price, Stock: r.Stock, Active: r.Active})
		}
	}
	for _, r := range images {
		if p := byID[r.ProductID]; p != nil {
			p.ImageKeys = append(p.ImageKeys, r.ObjectKey)
		}
	}
	out := make([]domain.Product, 0, len(ids))
	for _, id := range ids {
		if p := byID[id]; p != nil {
			out = append(out, *p)
		}
	}
	return out, nil
}

// ListShopProducts pages through shopID's products, newest first, optionally
// filtered by status.
func (s *Store) ListShopProducts(ctx context.Context, shopID uuid.UUID, status *domain.ProductStatus, cursor string, limit int) (domain.Page[domain.Product], error) {
	after, err := domain.DecodeCursor(cursor, sellerListSort)
	if err != nil {
		return domain.Page[domain.Product]{}, err
	}
	params := sqlcdb.ListShopProductIDsParams{ShopID: shopID, Status: (*string)(status), MaxRows: int32(limit + 1)}
	if after != nil {
		var ts time.Time
		if err := after.DecodeValue(&ts); err != nil {
			return domain.Page[domain.Product]{}, err
		}
		params.AfterCreatedAt, params.AfterID = &ts, &after.ID
	}
	rows, err := s.q.ListShopProductIDs(ctx, params)
	if err != nil {
		return domain.Page[domain.Product]{}, err
	}
	var next *string
	if len(rows) > limit {
		rows = rows[:limit]
		last := rows[len(rows)-1]
		c, err := domain.EncodeCursor(sellerListSort, last.CreatedAt, last.ID)
		if err != nil {
			return domain.Page[domain.Product]{}, err
		}
		next = &c
	}
	ids := make([]uuid.UUID, len(rows))
	for i, r := range rows {
		ids[i] = r.ID
	}
	items, err := s.Products(ctx, ids)
	if err != nil {
		return domain.Page[domain.Product]{}, err
	}
	return domain.Page[domain.Product]{Items: items, NextCursor: next}, nil
}
```

```go
package postgres

import (
	"context"
	"fmt"
	"strings"
	"time"

	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/domain"
)

// sortSpec describes how one SearchSort maps to SQL.
type sortSpec struct {
	expr string // sort key expression; "%[1]s" is replaced by the tsquery placeholder
	cast string // SQL type of the cursor value
	desc bool
	zero func() any // new pointer for decoding the cursor value
}

var sortSpecs = map[domain.SearchSort]sortSpec{
	domain.SortNewest:    {expr: "p.created_at", cast: "timestamptz", desc: true, zero: func() any { return new(time.Time) }},
	domain.SortPriceAsc:  {expr: "p.min_price", cast: "bigint", zero: func() any { return new(int64) }},
	domain.SortPriceDesc: {expr: "p.min_price", cast: "bigint", desc: true, zero: func() any { return new(int64) }},
	// ts_rank returns real; the cursor stores it as float32 so comparisons are exact.
	domain.SortRelevance: {expr: "ts_rank(p.search_vector, %[1]s)", cast: "real", desc: true, zero: func() any { return new(float32) }},
}

// SearchProducts runs a public search. p must be normalized (Sort and Limit set).
func (s *Store) SearchProducts(ctx context.Context, p domain.SearchParams) (domain.Page[domain.ProductSummary], error) {
	spec, ok := sortSpecs[p.Sort]
	if !ok {
		return domain.Page[domain.ProductSummary]{}, fmt.Errorf("search: unsupported sort %q", p.Sort)
	}
	after, err := domain.DecodeCursor(p.Cursor, string(p.Sort))
	if err != nil {
		return domain.Page[domain.ProductSummary]{}, err
	}

	var args []any
	bind := func(v any) string {
		args = append(args, v)
		return fmt.Sprintf("$%d", len(args))
	}
	where := []string{"p.status = 'active'", "p.min_price IS NOT NULL"}
	tsquery := ""
	if p.Query != "" {
		tsquery = "websearch_to_tsquery('simple', vn_unaccent(" + bind(p.Query) + "))"
		where = append(where, "p.search_vector @@ "+tsquery)
	}
	sortExpr := spec.expr
	if strings.Contains(sortExpr, "%[1]s") {
		sortExpr = fmt.Sprintf(sortExpr, tsquery)
	}
	if p.CategorySlug != "" {
		c := bind(p.CategorySlug)
		where = append(where, "p.category_id IN (SELECT c.id FROM categories c WHERE c.slug = "+c+
			" OR c.parent_id IN (SELECT id FROM categories WHERE slug = "+c+"))")
	}
	if p.ShopSlug != "" {
		where = append(where, "s.slug = "+bind(p.ShopSlug))
	}
	if p.MinPrice != nil {
		where = append(where, "p.min_price >= "+bind(*p.MinPrice))
	}
	if p.MaxPrice != nil {
		where = append(where, "p.min_price <= "+bind(*p.MaxPrice))
	}
	dir, cmp := "ASC", ">"
	if spec.desc {
		dir, cmp = "DESC", "<"
	}
	if after != nil {
		v := spec.zero()
		if err := after.DecodeValue(v); err != nil {
			return domain.Page[domain.ProductSummary]{}, err
		}
		where = append(where, fmt.Sprintf("(%s, p.id) %s (%s::%s, %s::uuid)", sortExpr, cmp, bind(v), spec.cast, bind(after.ID)))
	}

	sql := `SELECT p.id, p.name, p.min_price, s.id, s.name, s.slug,
       coalesce((SELECT i.object_key FROM product_images i WHERE i.product_id = p.id ORDER BY i.position LIMIT 1), ''),
       ` + sortExpr + `
FROM products p JOIN shops s ON s.id = p.shop_id
WHERE ` + strings.Join(where, " AND ") + `
ORDER BY ` + sortExpr + ` ` + dir + `, p.id ` + dir + `
LIMIT ` + bind(p.Limit+1)

	rows, err := s.pool.Query(ctx, sql, args...)
	if err != nil {
		return domain.Page[domain.ProductSummary]{}, fmt.Errorf("search products: %w", err)
	}
	defer rows.Close()
	var (
		items []domain.ProductSummary
		keys  []any
	)
	for rows.Next() {
		var (
			it      domain.ProductSummary
			sortKey any
		)
		if err := rows.Scan(&it.ID, &it.Name, &it.MinPrice, &it.Shop.ID, &it.Shop.Name, &it.Shop.Slug, &it.ImageKey, &sortKey); err != nil {
			return domain.Page[domain.ProductSummary]{}, fmt.Errorf("scan search row: %w", err)
		}
		items = append(items, it)
		keys = append(keys, sortKey)
	}
	if err := rows.Err(); err != nil {
		return domain.Page[domain.ProductSummary]{}, fmt.Errorf("search products: %w", err)
	}

	page := domain.Page[domain.ProductSummary]{Items: items}
	if page.Items == nil {
		page.Items = []domain.ProductSummary{}
	}
	if len(items) > p.Limit {
		page.Items = items[:p.Limit]
		c, err := domain.EncodeCursor(string(p.Sort), keys[p.Limit-1], items[p.Limit-1].ID)
		if err != nil {
			return domain.Page[domain.ProductSummary]{}, err
		}
		page.NextCursor = &c
	}
	return page, nil
}
```

Scanning the sort key into `any` yields `time.Time` (timestamptz), `int64` (bigint) or `float32` (real), which `EncodeCursor` marshals and `DecodeValue` reads back into the same types.

```sql
-- name: LockOrder :exec
-- Serializes every stock transaction of one order (idempotency, WS2 §3).
SELECT pg_advisory_xact_lock(hashtextextended(sqlc.arg('order_id')::text, 0));

-- name: OrderHasReservations :one
SELECT EXISTS (SELECT 1 FROM stock_reservations WHERE order_id = $1);

-- name: DecrementStock :execrows
UPDATE skus s SET stock = s.stock - sqlc.arg('qty')::int, updated_at = now()
FROM products p
WHERE s.id = sqlc.arg('sku_id') AND p.id = s.product_id AND p.status = 'active'
  AND s.active AND s.stock >= sqlc.arg('qty')::int;

-- name: AvailableStock :one
SELECT (CASE WHEN s.active AND p.status = 'active' THEN s.stock ELSE 0 END)::int AS available
FROM skus s JOIN products p ON p.id = s.product_id
WHERE s.id = $1;

-- name: InsertReservation :exec
INSERT INTO stock_reservations (order_id, sku_id, quantity, status) VALUES ($1, $2, $3, 'reserved');

-- name: LockReservedForOrder :many
SELECT sku_id, quantity FROM stock_reservations
WHERE order_id = $1 AND status = 'reserved'
ORDER BY sku_id
FOR UPDATE;

-- name: IncrementStock :exec
UPDATE skus SET stock = stock + sqlc.arg('qty')::int, updated_at = now() WHERE id = sqlc.arg('sku_id');

-- name: MarkReleased :exec
UPDATE stock_reservations SET status = 'released', updated_at = now()
WHERE order_id = $1 AND status = 'reserved';

-- name: InsertProcessedEvent :execrows
INSERT INTO processed_events (event_id) VALUES ($1) ON CONFLICT DO NOTHING;

-- name: GetSkuInfos :many
SELECT s.id AS sku_id, s.name AS variant_name, s.price, s.stock, s.active AS sku_active,
       p.id AS product_id, p.name AS product_name, p.status AS product_status,
       sh.id AS shop_id, sh.name AS shop_name, sh.slug AS shop_slug, sh.owner_user_id,
       coalesce((SELECT i.object_key FROM product_images i WHERE i.product_id = p.id
                 ORDER BY i.position LIMIT 1), '')::text AS image_key
FROM skus s
JOIN products p ON p.id = s.product_id
JOIN shops sh ON sh.id = p.shop_id
WHERE s.id = ANY(sqlc.arg('ids')::uuid[]);
```

```go
// SkuInfos returns order-facing SKU data; unknown ids are omitted.
func (s *Store) SkuInfos(ctx context.Context, ids []uuid.UUID) ([]domain.SkuInfo, error) {
	if len(ids) == 0 {
		return []domain.SkuInfo{}, nil
	}
	rows, err := s.q.GetSkuInfos(ctx, ids)
	if err != nil {
		return nil, err
	}
	out := make([]domain.SkuInfo, len(rows))
	for i, r := range rows {
		out[i] = domain.SkuInfo{
			SkuID: r.SkuID, ProductID: r.ProductID, ProductName: r.ProductName, VariantName: r.VariantName,
			ImageKey: r.ImageKey, Price: r.Price, Stock: r.Stock,
			Available: r.SkuActive && r.ProductStatus == string(domain.StatusActive),
			ShopID:    r.ShopID, ShopName: r.ShopName, ShopSlug: r.ShopSlug, SellerUserID: r.OwnerUserID,
		}
	}
	return out, nil
}

// ReserveStock atomically reserves items for orderID. items must be
// normalized (merged and sorted by SKU id, so row locks are taken in a
// global order). A repeated call for the same order is a no-op.
func (s *Store) ReserveStock(ctx context.Context, orderID uuid.UUID, items []domain.StockItem) error {
	return pgxx.WithTx(ctx, s.pool, func(tx pgx.Tx) error {
		q := s.q.WithTx(tx)
		if err := q.LockOrder(ctx, orderID.String()); err != nil {
			return err
		}
		reserved, err := q.OrderHasReservations(ctx, orderID)
		if err != nil {
			return err
		}
		if reserved {
			return nil
		}
		var shortages []domain.StockShortage
		for _, it := range items {
			n, err := q.DecrementStock(ctx, sqlcdb.DecrementStockParams{Qty: it.Quantity, SkuID: it.SkuID})
			if err != nil {
				return err
			}
			if n == 1 {
				continue
			}
			available, err := q.AvailableStock(ctx, it.SkuID)
			if errors.Is(err, pgx.ErrNoRows) {
				available = 0
			} else if err != nil {
				return err
			}
			shortages = append(shortages, domain.StockShortage{SkuID: it.SkuID, Requested: it.Quantity, Available: available})
		}
		if len(shortages) > 0 {
			return &domain.InsufficientStockError{Shortages: shortages} // rolls back every decrement
		}
		for _, it := range items {
			if err := q.InsertReservation(ctx, sqlcdb.InsertReservationParams{OrderID: orderID, SkuID: it.SkuID, Quantity: it.Quantity}); err != nil {
				return err
			}
		}
		return nil
	})
}

// ReleaseStock returns the reserved stock of orderID; a no-op when nothing is reserved.
func (s *Store) ReleaseStock(ctx context.Context, orderID uuid.UUID) error {
	return pgxx.WithTx(ctx, s.pool, func(tx pgx.Tx) error {
		return release(ctx, s.q.WithTx(tx), orderID)
	})
}

// ReleaseStockForEvent releases orderID once per eventID: the event id is
// recorded in processed_events in the same transaction.
func (s *Store) ReleaseStockForEvent(ctx context.Context, eventID, orderID uuid.UUID) error {
	return pgxx.WithTx(ctx, s.pool, func(tx pgx.Tx) error {
		q := s.q.WithTx(tx)
		n, err := q.InsertProcessedEvent(ctx, eventID)
		if err != nil {
			return err
		}
		if n == 0 {
			return nil // already processed
		}
		return release(ctx, q, orderID)
	})
}

func release(ctx context.Context, q *sqlcdb.Queries, orderID uuid.UUID) error {
	if err := q.LockOrder(ctx, orderID.String()); err != nil {
		return err
	}
	rows, err := q.LockReservedForOrder(ctx, orderID) // ordered by sku_id
	if err != nil {
		return err
	}
	for _, r := range rows {
		if err := q.IncrementStock(ctx, sqlcdb.IncrementStockParams{Qty: r.Quantity, SkuID: r.SkuID}); err != nil {
			return err
		}
	}
	if len(rows) == 0 {
		return nil
	}
	return q.MarkReleased(ctx, orderID)
}
```

```go
// Package grpctest provides in-process gRPC servers for tests (bufconn) and
// a fake IdentityInternal service.
package grpctest

import (
	"context"
	"net"
	"testing"

	"google.golang.org/grpc"
	"google.golang.org/grpc/credentials/insecure"
	"google.golang.org/grpc/test/bufconn"
)

// Serve starts an in-memory gRPC server with the services added by register
// and returns a client connection to it. Both are closed when t ends.
func Serve(t testing.TB, register func(*grpc.Server)) *grpc.ClientConn {
	t.Helper()
	lis := bufconn.Listen(1 << 20)
	srv := grpc.NewServer()
	register(srv)
	go func() { _ = srv.Serve(lis) }()
	conn, err := grpc.NewClient("passthrough:///bufconn",
		grpc.WithContextDialer(func(ctx context.Context, _ string) (net.Conn, error) { return lis.DialContext(ctx) }),
		grpc.WithTransportCredentials(insecure.NewCredentials()))
	if err != nil {
		t.Fatalf("dial bufconn: %v", err)
	}
	t.Cleanup(func() {
		_ = conn.Close()
		srv.Stop()
	})
	return conn
}
```

```go
package grpctest

import (
	"context"
	"sync"
	"testing"
	"time"

	"google.golang.org/grpc"
	"google.golang.org/grpc/status"
	"google.golang.org/protobuf/proto"

	identityv1 "github.com/ngoxuanchien/e-commerce/gen/identity/v1"
)

// FakeIdentity records GrantRole calls and can be told to fail or stall.
type FakeIdentity struct {
	identityv1.UnimplementedIdentityInternalServer

	mu    sync.Mutex
	calls []*identityv1.GrantRoleRequest
	err   error
	delay time.Duration
}

// StartFakeIdentity serves a new FakeIdentity over bufconn.
func StartFakeIdentity(t testing.TB) (*FakeIdentity, *grpc.ClientConn) {
	t.Helper()
	f := &FakeIdentity{}
	conn := Serve(t, func(s *grpc.Server) { identityv1.RegisterIdentityInternalServer(s, f) })
	return f, conn
}

// SetError makes subsequent calls fail with err (nil restores success).
func (f *FakeIdentity) SetError(err error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	f.err = err
}

// SetDelay makes subsequent calls wait d (or until the caller's deadline).
func (f *FakeIdentity) SetDelay(d time.Duration) {
	f.mu.Lock()
	defer f.mu.Unlock()
	f.delay = d
}

// Calls returns copies of the requests received so far.
func (f *FakeIdentity) Calls() []*identityv1.GrantRoleRequest {
	f.mu.Lock()
	defer f.mu.Unlock()
	out := make([]*identityv1.GrantRoleRequest, len(f.calls))
	for i, c := range f.calls {
		out[i] = proto.Clone(c).(*identityv1.GrantRoleRequest)
	}
	return out
}

// GrantRole implements identityv1.IdentityInternalServer.
func (f *FakeIdentity) GrantRole(ctx context.Context, req *identityv1.GrantRoleRequest) (*identityv1.GrantRoleResponse, error) {
	f.mu.Lock()
	f.calls = append(f.calls, proto.Clone(req).(*identityv1.GrantRoleRequest))
	err, delay := f.err, f.delay
	f.mu.Unlock()
	if delay > 0 {
		select {
		case <-time.After(delay):
		case <-ctx.Done():
			return nil, status.FromContextError(ctx.Err()).Err()
		}
	}
	if err != nil {
		return nil, err
	}
	return &identityv1.GrantRoleResponse{}, nil
}
```

```go
// ShopService opens and manages shops.
type ShopService struct {
	store        ShopStore
	roles        RoleGranter
	grantTimeout time.Duration
}

// NewShopService returns a ShopService using GrantRoleTimeout.
func NewShopService(store ShopStore, roles RoleGranter) *ShopService {
	return &ShopService{store: store, roles: roles, grantTimeout: GrantRoleTimeout}
}

// WithGrantTimeout returns a copy using d as the GrantRole timeout.
func (s *ShopService) WithGrantTimeout(d time.Duration) *ShopService {
	c := *s
	c.grantTimeout = d
	return &c
}

// Open creates owner's shop and grants them the seller role in one
// transaction: if GrantRole fails or times out, no shop is created.
func (s *ShopService) Open(ctx context.Context, owner uuid.UUID, in domain.ShopInput) (domain.Shop, error) {
	in, err := in.Validate()
	if err != nil {
		return domain.Shop{}, err
	}
	id, err := uuid.NewV7()
	if err != nil {
		return domain.Shop{}, err
	}
	shop := domain.Shop{ID: id, OwnerUserID: owner, Name: in.Name, Slug: in.Slug, Description: in.Description}
	return s.store.CreateShop(ctx, shop, func(ctx context.Context) error {
		gctx, cancel := context.WithTimeout(ctx, s.grantTimeout)
		defer cancel()
		if err := s.roles.GrantSeller(gctx, owner); err != nil {
			return fmt.Errorf("%w: grant seller role: %w", domain.ErrUpstreamUnavailable, err)
		}
		return nil
	})
}

// Mine returns owner's shop (domain.ErrNotFound when they have none).
func (s *ShopService) Mine(ctx context.Context, owner uuid.UUID) (domain.Shop, error) {
	return s.store.ShopByOwner(ctx, owner)
}

// BySlug returns the shop with slug.
func (s *ShopService) BySlug(ctx context.Context, slug string) (domain.Shop, error) {
	return s.store.ShopBySlug(ctx, slug)
}

// Update changes the name/description of owner's shop.

	p, err := p.Validate()
	if err != nil {
		return domain.Shop{}, err
```

```go
// ProductService manages a seller's products and serves product detail.
type ProductService struct {

// NewProductService returns a ProductService.
func NewProductService(store ProductStore, presigner Presigner) *ProductService {

}

// Get returns product id as seen by viewer (uuid.Nil = anonymous). Non-active
// products are visible only to their shop owner, who also sees inactive SKUs.
func (s *ProductService) Get(ctx context.Context, id, viewer uuid.UUID) (domain.Product, error) {
	p, err := s.one(ctx, id)
	if err != nil {
		return domain.Product{}, err
	}
	if viewer != uuid.Nil && viewer == p.OwnerUserID {
		return p, nil
	}
	if p.Status != domain.StatusActive {
		return domain.Product{}, domain.ErrNotFound
	}
	return p.PublicView(), nil
}

// Create adds a product to owner's shop.
func (s *ProductService) Create(ctx context.Context, owner uuid.UUID, in domain.ProductInput) (domain.Product, error) {
	shop, err := s.shopOf(ctx, owner)
	if err != nil {
		return domain.Product{}, err
	}
	change, err := in.Validate(shop.ID, true)
	if err != nil {
		return domain.Product{}, err
	}
	id, err := s.store.CreateProduct(ctx, shop.ID, change)
	if err != nil {
		return domain.Product{}, err
	}
	return s.one(ctx, id)
}

// Update applies a partial update to one of owner's products.
func (s *ProductService) Update(ctx context.Context, owner, id uuid.UUID, in domain.ProductInput) (domain.Product, error) {
	shop, err := s.shopOf(ctx, owner)
	if err != nil {
		return domain.Product{}, err
	}
	change, err := in.Validate(shop.ID, false)
	if err != nil {
		return domain.Product{}, err
	}
	if err := s.store.UpdateProduct(ctx, shop.ID, id, change); err != nil {
		return domain.Product{}, err
	}
	return s.one(ctx, id)
}

// Archive archives one of owner's products.
func (s *ProductService) Archive(ctx context.Context, owner, id uuid.UUID) error {
	shop, err := s.shopOf(ctx, owner)
	if err != nil {
		return err
	}
	return s.store.ArchiveProduct(ctx, shop.ID, id)
}

// ListMine pages through owner's products (all statuses unless filtered).
func (s *ProductService) ListMine(ctx context.Context, owner uuid.UUID, status *domain.ProductStatus, cursor string, limit int) (domain.Page[domain.Product], error) {
	shop, err := s.shopOf(ctx, owner)
	if err != nil {
		return domain.Page[domain.Product]{}, err
	}
	if limit, err = domain.NormalizeLimit(limit); err != nil {
		return domain.Page[domain.Product]{}, err
	}
	return s.store.ListShopProducts(ctx, shop.ID, status, cursor, limit)
}

// PresignUpload issues a presigned POST for one image of owner's shop.
func (s *ProductService) PresignUpload(ctx context.Context, owner uuid.UUID, contentType string) (domain.Upload, error) {
	shop, err := s.shopOf(ctx, owner)
	if err != nil {
		return domain.Upload{}, err
	}
	if _, ok := domain.ImageExtension(contentType); !ok {
		return domain.Upload{}, &domain.ValidationError{Fields: map[string]string{
			"content_type": "must be one of: image/jpeg image/png image/webp",
		}}
	}
	return s.presigner.PresignImageUpload(ctx, shop.ID, contentType)
}

func (s *ProductService) shopOf(ctx context.Context, owner uuid.UUID) (domain.Shop, error) {
	shop, err := s.store.ShopByOwner(ctx, owner)
	if errors.Is(err, domain.ErrNotFound) {
		return domain.Shop{}, domain.ErrNoShop
	}
	return shop, err
}

func (s *ProductService) one(ctx context.Context, id uuid.UUID) (domain.Product, error) {
	ps, err := s.store.Products(ctx, []uuid.UUID{id})
	if err != nil {
		return domain.Product{}, err
	}
	if len(ps) == 0 {
		return domain.Product{}, domain.ErrNotFound
	}
	return ps[0], nil
}
```

```go
// GetSkus returns SKU data for up to domain.MaxSkuLookup ids (duplicates ignored).
func (s *InventoryService) GetSkus(ctx context.Context, ids []uuid.UUID) ([]domain.SkuInfo, error) {
	if len(ids) > domain.MaxSkuLookup {
		return nil, &domain.ValidationError{Fields: map[string]string{
			"sku_ids": fmt.Sprintf("must have at most %d items", domain.MaxSkuLookup),
		}}
	}
	seen := make(map[uuid.UUID]bool, len(ids))
	unique := make([]uuid.UUID, 0, len(ids))
	for _, id := range ids {
		if !seen[id] {
			seen[id] = true
			unique = append(unique, id)
		}
	}
	return s.store.SkuInfos(ctx, unique)
}

}
```

```go
import (
	"context"

	"github.com/google/uuid"
```

```go
	"google.golang.org/grpc/status"
```

```go
// Inventory is the use-case port behind CatalogInternal.
type Inventory interface {
	GetSkus(ctx context.Context, ids []uuid.UUID) ([]domain.SkuInfo, error)
	Reserve(ctx context.Context, orderID uuid.UUID, items []domain.StockItem) error
	Release(ctx context.Context, orderID uuid.UUID) error
}

// CatalogServer implements catalogv1.CatalogInternalServer.
type CatalogServer struct {
	catalogv1.UnimplementedCatalogInternalServer
	inv    Inventory
	assets domain.AssetBase
}

// NewCatalogServer returns a CatalogServer; assets builds image URLs.
func NewCatalogServer(inv Inventory, assets domain.AssetBase) *CatalogServer {
	return &CatalogServer{inv: inv, assets: assets}
}

// GetSkus returns SkuInfo for known SKUs; unknown or malformed ids are omitted.
func (s *CatalogServer) GetSkus(ctx context.Context, req *catalogv1.GetSkusRequest) (*catalogv1.GetSkusResponse, error) {
	if n := len(req.GetSkuIds()); n > domain.MaxSkuLookup {
		return nil, status.Errorf(codes.InvalidArgument, "at most %d sku_ids per call, got %d", domain.MaxSkuLookup, n)
	}
	ids := make([]uuid.UUID, 0, len(req.GetSkuIds()))
	for _, raw := range req.GetSkuIds() {
		if id, err := uuid.Parse(raw); err == nil {
			ids = append(ids, id)
		}
	}
	infos, err := s.inv.GetSkus(ctx, ids)
	if err != nil {
		return nil, toStatus(ctx, err)
	}
	resp := &catalogv1.GetSkusResponse{Skus: make([]*catalogv1.SkuInfo, 0, len(infos))}
	for _, in := range infos {
		resp.Skus = append(resp.Skus, &catalogv1.SkuInfo{
			SkuId: in.SkuID.String(), ProductId: in.ProductID.String(), ProductName: in.ProductName,
			VariantName: in.VariantName, ImageUrl: s.assets.URL(in.ImageKey), Price: in.Price, Stock: in.Stock,
			Available: in.Available, ShopId: in.ShopID.String(), ShopName: in.ShopName,
			SellerUserId: in.SellerUserID.String(), ShopSlug: in.ShopSlug,
		})
	}
	return resp, nil
}

// ReserveStock reserves stock for an order (idempotent per order_id).
func (s *CatalogServer) ReserveStock(ctx context.Context, req *catalogv1.ReserveStockRequest) (*catalogv1.ReserveStockResponse, error) {
	orderID, err := uuid.Parse(req.GetOrderId())
	if err != nil {
		return nil, status.Error(codes.InvalidArgument, "order_id must be a UUID")
	}
	items := make([]domain.StockItem, len(req.GetItems()))
	for i, it := range req.GetItems() {
		sku, err := uuid.Parse(it.GetSkuId())
		if err != nil {
			return nil, status.Errorf(codes.InvalidArgument, "items[%d].sku_id must be a UUID", i)
		}
		items[i] = domain.StockItem{SkuID: sku, Quantity: it.GetQuantity()}
	}
	if err := s.inv.Reserve(ctx, orderID, items); err != nil {
		return nil, toStatus(ctx, err)
	}
	return &catalogv1.ReserveStockResponse{}, nil
}

// ReleaseStock releases an order's reservation (idempotent; OK when nothing is reserved).
func (s *CatalogServer) ReleaseStock(ctx context.Context, req *catalogv1.ReleaseStockRequest) (*catalogv1.ReleaseStockResponse, error) {
	orderID, err := uuid.Parse(req.GetOrderId())
	if err != nil {
		return nil, status.Error(codes.InvalidArgument, "order_id must be a UUID")
	}
	if err := s.inv.Release(ctx, orderID); err != nil {
		return nil, toStatus(ctx, err)
	}
	return &catalogv1.ReleaseStockResponse{}, nil
}

// toStatus maps domain errors to gRPC statuses (WS0 §5).
func toStatus(ctx context.Context, err error) error {
	var (
		ise *domain.InsufficientStockError
		ve  *domain.ValidationError
	)
	switch {
	case errors.As(err, &ise):
		detail := &catalogv1.InsufficientStock{}
		for _, sh := range ise.Shortages {
			detail.Shortages = append(detail.Shortages, &catalogv1.StockShortage{
				SkuId: sh.SkuID.String(), Requested: sh.Requested, Available: sh.Available,
			})
		}
		st := status.New(codes.FailedPrecondition, "insufficient stock")
		if withDetail, derr := st.WithDetails(detail); derr == nil {
			st = withDetail
		}
		return st.Err()
	case errors.As(err, &ve):
		return status.Error(codes.InvalidArgument, ve.Error())
	case errors.Is(err, domain.ErrNotFound):
		return status.Error(codes.NotFound, "not found")
	case errors.Is(err, context.Canceled), errors.Is(err, context.DeadlineExceeded):
		return status.FromContextError(err).Err()
	default:
		slog.ErrorContext(ctx, "catalog rpc failed", "error", err)
		return status.Error(codes.Internal, "internal error")
	}
}
```

```go
package storage

import (
	"context"
	"errors"
	"fmt"
	"strings"
	"time"

	"github.com/google/uuid"
	"github.com/minio/minio-go/v7"
	"github.com/minio/minio-go/v7/pkg/credentials"

	"github.com/ngoxuanchien/e-commerce/services/catalog/internal/domain"
)

// Config configures the presigner. PublicBaseURL is the browser-reachable,
// path-style bucket URL (PUBLIC_ASSET_BASE_URL); uploads are POSTed there and
// images are served from it. Endpoint may be an in-cluster address: a POST
// policy signature does not cover the host.
type Config struct {
	Endpoint      string
	AccessKey     string
	SecretKey     string
	Bucket        string
	UseSSL        bool
	PublicBaseURL string
}

// Presigner creates upload forms and checks bucket readiness.
type Presigner struct {
	client *minio.Client
	bucket string
	public domain.AssetBase
}

// New returns a Presigner. It does not contact MinIO.
func New(cfg Config) (*Presigner, error) {
	client, err := minio.New(cfg.Endpoint, &minio.Options{
		Creds:  credentials.NewStaticV4(cfg.AccessKey, cfg.SecretKey, ""),
		Secure: cfg.UseSSL,
		Region: "us-east-1", // fixed so presigning never needs a bucket-location round trip
	})
	if err != nil {
		return nil, fmt.Errorf("minio client: %w", err)
	}
	return &Presigner{client: client, bucket: cfg.Bucket, public: domain.AssetBase(strings.TrimRight(cfg.PublicBaseURL, "/"))}, nil
}

// PresignImageUpload returns a POST form for one image of shopID: exact key
// shops/{shop_id}/{uuid}.{ext}, exact content type, 1 B–5 MB, valid 10 min.
func (p *Presigner) PresignImageUpload(ctx context.Context, shopID uuid.UUID, contentType string) (domain.Upload, error) {
	ext, ok := domain.ImageExtension(contentType)
	if !ok {
		return domain.Upload{}, &domain.ValidationError{Fields: map[string]string{
			"content_type": "must be one of: image/jpeg image/png image/webp",
		}}
	}
	id, err := uuid.NewV7()
	if err != nil {
		return domain.Upload{}, err
	}
	key := domain.ImageKeyPrefix(shopID) + id.String() + "." + ext

	policy := minio.NewPostPolicy()
	if err := errors.Join(
		policy.SetBucket(p.bucket),
		policy.SetKey(key),
		policy.SetContentType(contentType),
		policy.SetContentLengthRange(1, domain.MaxImageBytes),
		policy.SetExpires(time.Now().UTC().Add(domain.UploadTTL)),
	); err != nil {
		return domain.Upload{}, fmt.Errorf("build post policy: %w", err)
	}
	_, fields, err := p.client.PresignedPostPolicy(ctx, policy)
	if err != nil {
		return domain.Upload{}, fmt.Errorf("presign post policy: %w", err)
	}
	return domain.Upload{URL: string(p.public), Fields: fields, ObjectKey: key, PublicURL: p.public.URL(key)}, nil
}

// Ping reports whether the bucket exists and is reachable.
func (p *Presigner) Ping(ctx context.Context) error {
	ok, err := p.client.BucketExists(ctx, p.bucket)
	if err != nil {
		return fmt.Errorf("minio: %w", err)
	}
	if !ok {
		return fmt.Errorf("minio: bucket %q does not exist", p.bucket)
	}
	return nil
}
```

```go
// writeError maps domain errors to the REST error model (WS0 §3).
func writeError(w http.ResponseWriter, r *http.Request, err error) {
	var (
		ve *domain.ValidationError
		ce *domain.ConflictError
	)
	switch {
	case errors.As(err, &ve):
		err = httpx.ValidationError(ve.Fields)
	case errors.As(err, &ce):
		err = httpx.NewError(httpx.CodeConflict, ce.Message)
	case errors.Is(err, domain.ErrNotFound):
		err = httpx.NewError(httpx.CodeNotFound, "not found")
	case errors.Is(err, domain.ErrNoShop):
		err = httpx.NewError(httpx.CodeForbidden, "open a shop first")
	case errors.Is(err, domain.ErrUpstreamUnavailable):
		err = httpx.NewError(httpx.CodeUpstreamUnavailable, "identity service unavailable, please retry").Wrap(err)
	}
	httpx.WriteError(w, r, err)
}
```

```go
// callerID returns the authenticated user id; a non-UUID id is unauthenticated.
func callerID(r *http.Request) (uuid.UUID, error) {
	id, err := uuid.Parse(authctx.UserID(r.Context()))
	if err != nil {
		return uuid.Nil, httpx.NewError(httpx.CodeUnauthenticated, "authentication required")
	}
	return id, nil
}

// viewerID returns the caller's id, or uuid.Nil for anonymous callers.
func viewerID(r *http.Request) uuid.UUID {
	id, _ := uuid.Parse(authctx.UserID(r.Context()))
	return id
}

// parseLimit reads ?limit= (absent → 0, meaning the default); errors go to f.
func parseLimit(q url.Values, f map[string]string) int {
	raw := q.Get("limit")
	if raw == "" {
		return 0
	}
	n, err := strconv.Atoi(raw)
	if err != nil || n < 1 || n > domain.MaxPageLimit {
		f["limit"] = "must be an integer between 1 and 100"
		return 0
	}
	return n
}

// parseMoney reads an optional non-negative integer amount; errors go to f.
func parseMoney(q url.Values, name string, f map[string]string) *int64 {
	raw := q.Get(name)
	if raw == "" {
		return nil
	}
	n, err := strconv.ParseInt(raw, 10, 64)
	if err != nil || n < 0 {
		f[name] = "must be a non-negative integer"
		return nil
	}
	return &n
}
```

```go
// NewRouter returns the /api handler. The caller applies authctx.Middleware
// so X-User-Id / X-User-Roles are available in the request context.
func NewRouter(d Deps) http.Handler {
	h := &handlers{Deps: d}
	user := authctx.RequireUser
	seller := authctx.RequireRole(authctx.RoleSeller)
	mux := http.NewServeMux()

	mux.HandleFunc("GET /api/categories", h.listCategories)
	mux.HandleFunc("GET /api/products", h.searchProducts)
	mux.HandleFunc("GET /api/products/{id}", h.getProduct)
	mux.HandleFunc("GET /api/shops/{slug}", h.getShop)

	mux.Handle("POST /api/shops", user(http.HandlerFunc(h.createShop)))
	mux.Handle("GET /api/shops/me", seller(http.HandlerFunc(h.getMyShop))) // more specific than {slug}
	mux.Handle("PATCH /api/shops/me", seller(http.HandlerFunc(h.updateMyShop)))

	mux.Handle("GET /api/seller/products", seller(http.HandlerFunc(h.listSellerProducts)))
	mux.Handle("POST /api/seller/products", seller(http.HandlerFunc(h.createSellerProduct)))
	mux.Handle("PATCH /api/seller/products/{id}", seller(http.HandlerFunc(h.updateSellerProduct)))
	mux.Handle("DELETE /api/seller/products/{id}", seller(http.HandlerFunc(h.archiveSellerProduct)))
	mux.Handle("POST /api/seller/uploads", seller(http.HandlerFunc(h.createUpload)))

	mux.Handle("/", httpx.NotFound())
	return mux
```

```go
// Package kafka consumes order.events: OrderCancelled returns reserved stock.
package kafka

import (
	"context"
	"log/slog"

	"github.com/google/uuid"

	"github.com/ngoxuanchien/e-commerce/pkg/event"
	"github.com/ngoxuanchien/e-commerce/pkg/kafkax"
)

// GroupID is catalog-svc's consumer group (WS2 §3).
const GroupID = "catalog-svc"

// Releaser releases an order's stock at most once per event.
type Releaser interface {
	ReleaseForEvent(ctx context.Context, eventID, orderID uuid.UUID) error
}

// Handler turns order events into stock releases.
type Handler struct {
	releaser Releaser
	logger   *slog.Logger
}

// NewHandler returns a Handler.
func NewHandler(r Releaser, logger *slog.Logger) *Handler {
	return &Handler{releaser: r, logger: logger}
}

// Handle processes one record. Records that can never succeed (undecodable,
// unsupported, malformed) are logged and skipped so they don't block the
// partition; release errors are returned so kafkax retries with backoff.
func (h *Handler) Handle(ctx context.Context, m kafkax.Message) error {
	env, err := event.Decode(m.Value)
	if err != nil {
		h.logger.WarnContext(ctx, "skipping undecodable order event", "error", err)
		return nil
	}
	if env.EventType != event.TypeOrderCancelled {
		return nil
	}
	data, err := event.DecodeData[event.OrderCancelled](env)
	if err != nil {
		h.logger.WarnContext(ctx, "skipping malformed OrderCancelled", "event_id", env.EventID, "error", err)
		return nil
	}
	eventID, err := uuid.Parse(env.EventID)
	if err != nil {
		h.logger.WarnContext(ctx, "skipping OrderCancelled with invalid event_id", "event_id", env.EventID)
		return nil
	}
	orderID, err := uuid.Parse(data.OrderID)
	if err != nil {
		h.logger.WarnContext(ctx, "skipping OrderCancelled with invalid order_id", "event_id", env.EventID, "order_id", data.OrderID)
		return nil
	}
	if err := h.releaser.ReleaseForEvent(ctx, eventID, orderID); err != nil {
		return err
	}
	h.logger.InfoContext(ctx, "released stock for cancelled order", "event_id", eventID, "order_id", orderID)
	return nil
}

// NewConsumer joins GroupID on event.TopicOrderEvents with h.
func NewConsumer(brokers []string, h *Handler, logger *slog.Logger) (*kafkax.Consumer, error) {
	return kafkax.NewConsumer(kafkax.ConsumerConfig{
		Brokers: brokers,
		Group:   GroupID,
		Topics:  []string{event.TopicOrderEvents},
		Logger:  logger,
	}, h.Handle)
}
```

````markdown
## How stock stays correct

- `ReserveStock` runs in one transaction: `pg_advisory_xact_lock(order_id)` →
  "already reserved?" (idempotency) → items merged and sorted by `sku_id` →
  `UPDATE skus SET stock = stock - q WHERE ... AND stock >= q` per item → any
  shortage rolls everything back and returns `FAILED_PRECONDITION` with
  `InsufficientStock`. `CHECK (stock >= 0)` is the last line of defence.
- `ReleaseStock` and the `OrderCancelled` consumer take the same order lock,
  lock `reserved` rows `FOR UPDATE`, add the quantities back and mark them
  `released`. The consumer also inserts the event id into `processed_events`
  in the same transaction, so redelivery is a no-op.

## Decisions beyond the spec

1. Packages `httpapi`/`grpcapi` avoid shadowing `net/http` and `grpc`.
2. `description` columns are `NOT NULL DEFAULT ''` (the contract always returns a string).
3. Extra caps: shop description ≤ 2,000, product description ≤ 5,000, SKU name 1–100 chars; text is trimmed.
4. `image_keys` must match `shops/{shop_id}/{uuid}.{jpg|png|webp}` exactly, without duplicates; object existence is not checked.
5. Unknown/inactive SKUs in `ReserveStock` are shortages with `available = 0`; malformed ids → `INVALID_ARGUMENT`. `GetSkus` omits malformed ids; > 100 ids → `INVALID_ARGUMENT`.
6. Known limitation: a `ReleaseStock` arriving before the first `ReserveStock` of an order leaves no tombstone (order-svc's sweeper covers this).
7. The cursor also encodes its sort; reusing it with another sort → 400. `sort=relevance` without `q` → `newest`.
8. Public product detail hides inactive SKUs; the owner sees everything.
9. `upload_url` = `PUBLIC_ASSET_BASE_URL` (path-style bucket URL) because `MINIO_ENDPOINT` is internal. Browser CORS on the bucket is a deploy concern.
10. Seller without a shop → 403 on `/api/seller/*`, 404 on `/api/shops/me`. Non-UUID `X-User-Id` → 401.
11. Poison Kafka records are logged and skipped; database errors are retried.
````
