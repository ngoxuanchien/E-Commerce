# P2 WS2' ledger-svc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `services/ledger`, a double-entry, append-only ledger. It consumes payment and order events, holds escrow, pays sellers and commission, serves the seller wallet API, runs simulated payouts, and ships a `trial-balance` command.

**Architecture:**
- **Hexagonal layout** as in order-svc:
  - `internal/domain` has pure posting builders (accounts, journal, Σ=0 checks).
  - `internal/app` has the poster (lock → replay check → overdraw check → insert), the event handlers, the payout service and the background jobs, all behind `Store`/`Tx` ports.
  - `internal/adapter/{postgres,kafka,http,bank}` implement the ports.
- **Invariants are enforced twice.** Database triggers check Σ=0, append-only and "no liability in debit" at commit. The code checks them again, under row locks, before inserting.
- **Idempotency** has two layers: the unique `journal_transactions.idempotency_key` and the `processed_events` inbox.

**Tech Stack:** Go 1.27.1, pgx/v5 + sqlc v1.31.1 (`make gen-sqlc`), golang-migrate (`pgxx.Migrate`), franz-go through `pkg/kafkax`, `pkg/{event,inbox,idemkey,outbox,httpx,authctx}`, testcontainers (`pkg/testutil`), `pgregory.net/rapid` for the property test, and kin-openapi / santhosh-tekuri jsonschema for the contract tests.

**Spec:** `docs/superpowers/specs/2026-09-29-marketplace-p2-ws2-ledger.md`. Also read ADR `docs/adr/0006-double-entry-ledger-service.md`, the WS0' spec `docs/superpowers/specs/2026-09-29-marketplace-p2-ws0-contracts.md` §3.3 and §5, and `api/openapi/ledger.yaml`.

## Review Focus

These five conditions aren't pinned by any line of the spec's test list, but they will bite first. Each one has a test in its owning task.

1. **A refund for an escrow that was already released.** The posting is rejected by invariant 3. It is logged with `alert=true` and **skipped**, not retried forever: `kafkax` retries a returned error endlessly and would block the partition. Balances stay unchanged. See Task 4, `TestRefundAfterReleaseIsRejectedAndSkipped`.
2. **A second `PaymentSucceeded`** (a different `payment_id`) whose allocations name orders that were already captured. It must not credit the escrow twice. The `PAY` is kept, so the money waits in suspense; the capture is skipped and logged. See Task 4, `TestSecondPaymentForCapturedOrdersDoesNotDoubleCapture`.
3. **Payout `Idempotency-Key` retries:**
   - the same key and body replays the same response (one payout, one debit);
   - the same key with another amount gives 422;
   - a retry after a stored 409 `INSUFFICIENT_FUNDS` replays the 409, even if funds arrived since.

   See Task 5.
4. **A seller who has never been paid** calls every wallet route. They get zeros and empty pages, not 404 or 500. See Tasks 6 and 7.
5. **Malformed events** must be skipped, never retried forever:
   - undecodable JSON, an unknown event type, P1-era payloads;
   - non-UUID ids, amounts ≤ 0, an unknown provider;
   - allocations that exceed the payment, commission ≥ amount.

   See Task 4, `TestMalformedEventsAreSkipped`, and Task 8, `TestHandlerSkipsUndecodable`.

## Decisions this plan makes (the spec is silent or ambiguous)

- **Permanent vs retryable.** `EventHandler.Handle` returns `nil` for anything that can never succeed:
  - decode failures, invalid ids or amounts, and domain validation errors;
  - `ErrWouldOverdraw`.

  For these, the transaction is rolled back and the event is logged at ERROR (`alert=true` for invariant rejections). Only infrastructure errors and `ErrAllocationMissing` (a refund before its capture, spec §6) are returned, so kafkax retries them.
- **DB-level invariant 3.** Besides the code check under `FOR UPDATE`, a deferred constraint trigger rejects any commit that leaves a liability account with `Σ > 0`. This is the "database enforces invariants 1–3" acceptance criterion. The lock is still what makes concurrent payouts correct.
- **Refund amounts come from the allocation** (like release, spec §6). If the event's `amount` or `provider` differs, that is logged as an error.
- **`escrow_allocations` is append-only too** (the same trigger as the journal), because the spec calls it immutable.
- **The payout minimum is validated before the idempotency claim.** A 400 is deterministic and needn't be stored.
- **`trial-balance`:** exit 0 means consistent, and exit 1 means inconsistent **or** unable to connect. The JSON goes to stdout and errors go to stderr.
- `settled_at` is set only for `SETTLED`. `FAILED` keeps `settled_at = null` and sets `failure_reason`.

// Package domain is ledger-svc's pure model (WS2' §2–§3): the chart of
// accounts, journal transactions and one builder per posting kind. It does
// no I/O; internal/app posts what these builders return.
package domain

import (
	"github.com/google/uuid"

	"github.com/ngoxuanchien/e-commerce/pkg/event"
)

// AccountType classifies an account. Liability and revenue accounts normally
// carry a credit (negative) balance.
type AccountType string

const (
	Asset     AccountType = "asset"
	Liability AccountType = "liability"
	Revenue   AccountType = "revenue"
)

// Account identifies a ledger account by its unique code. Accounts are
// created lazily the first time a posting uses them.
type Account struct {
	Code    string
	Type    AccountType
	OwnerID *uuid.UUID // the seller, for escrow, wallet and payout-pending accounts
	OrderID *uuid.UUID // escrow accounts only
}

// Fixed account codes and the escrow prefix (the in_escrow index predicate).
const (
	CodeCommissionRevenue = "platform_commission_revenue"
	CodePlatformCash      = "platform_cash"
	EscrowCodePrefix      = "escrow:"
)

// PSPClearing is money held at a provider for the platform.
func PSPClearing(provider string) Account {
	return Account{Code: "psp_clearing:" + provider, Type: Asset}
}

// CheckoutSuspense is money received for a checkout but not yet allocated.
func CheckoutSuspense(checkoutID uuid.UUID) Account {
	return Account{Code: "checkout_suspense:" + checkoutID.String(), Type: Liability}
}

// Escrow holds one order's share until the order completes or is refunded.
func Escrow(orderID, sellerID uuid.UUID) Account {
	return Account{Code: EscrowCodePrefix + orderID.String(), Type: Liability, OwnerID: &sellerID, OrderID: &orderID}
}

// SellerWallet is the seller's available balance.
func SellerWallet(sellerID uuid.UUID) Account {
	return Account{Code: "seller_wallet:" + sellerID.String(), Type: Liability, OwnerID: &sellerID}
}

// SellerPayoutPending holds requested, not yet settled withdrawals.
func SellerPayoutPending(sellerID uuid.UUID) Account {
	return Account{Code: "seller_payout_pending:" + sellerID.String(), Type: Liability, OwnerID: &sellerID}
}

// CommissionRevenue is the platform's commission income.
func CommissionRevenue() Account { return Account{Code: CodeCommissionRevenue, Type: Revenue} }

// PlatformCash is the simulated bank account payouts are paid from. P2 does
// not model provider settlement into it, so it goes negative (ADR-0006).
func PlatformCash() Account { return Account{Code: CodePlatformCash, Type: Asset} }

// ValidProvider reports whether p is a payment.events provider.
func ValidProvider(p string) bool {
	switch p {

package domain

import (
	"errors"
	"fmt"
	"time"

	"github.com/google/uuid"
)

// Kind is a journal transaction's posting kind (WS2' §3).
type Kind string

const (
	KindPay             Kind = "PAY"
	KindCapture         Kind = "CAPTURE"
	KindRelease         Kind = "RELEASE"
	KindRefund          Kind = "REFUND"
	KindDuplicateRefund Kind = "DUPLICATE_REFUND"
	KindPayoutRequest   Kind = "PAYOUT_REQUEST"
	KindPayoutSettle    Kind = "PAYOUT_SETTLE"
	KindPayoutFail      Kind = "PAYOUT_FAIL"
)

var (
	ErrInvalidPosting = errors.New("posting: invalid input")
	ErrTooFewLines    = errors.New("journal: a transaction needs at least two lines")
	ErrZeroLine       = errors.New("journal: a line amount must not be zero")
	ErrUnbalanced     = errors.New("journal: lines do not sum to zero")
)

// Line is one entry: debit > 0, credit < 0.
type Line struct {
	Account Account
	Amount  int64
}

// Refs are the business ids a transaction relates to (journal_transactions.refs).
type Refs struct {
	CheckoutID *uuid.UUID `json:"checkout_id,omitempty"`
	PaymentID  *uuid.UUID `json:"payment_id,omitempty"`
	OrderID    *uuid.UUID `json:"order_id,omitempty"`
	RefundID   *uuid.UUID `json:"refund_id,omitempty"`
	PayoutID   *uuid.UUID `json:"payout_id,omitempty"`
}

// Journal is one balanced journal transaction. Key is its idempotency key.
// SourceEventID and OccurredAt are stamped by the caller.
type Journal struct {
	Key           string
	Kind          Kind
	Refs          Refs
	Lines         []Line
	SourceEventID *uuid.UUID
	OccurredAt    time.Time
}

// Validate checks invariant 1 in code: a key and kind, at least two lines,
// no zero line, Σ = 0.
func (j Journal) Validate() error {
	if j.Key == "" || j.Kind == "" {
		return fmt.Errorf("%w: key and kind are required", ErrInvalidPosting)
	}
	if len(j.Lines) < 2 {
		return ErrTooFewLines
	}
	var sum int64
	for _, l := range j.Lines {
		if l.Amount == 0 {
			return ErrZeroLine
		}
		if l.Account.Code == "" {
			return fmt.Errorf("%w: line without account", ErrInvalidPosting)
		}
		sum += l.Amount
	}
	if sum != 0 {
		return fmt.Errorf("%w: sum is %d", ErrUnbalanced, sum)
	}
	return nil
}

// NetByAccount sums the lines per account, in first-seen order.
func (j Journal) NetByAccount() []Line {
	var out []Line
	index := map[string]int{}
	for _, l := range j.Lines {
		if i, ok := index[l.Account.Code]; ok {
			out[i].Amount += l.Amount
			continue
		}
		index[l.Account.Code] = len(out)
		out = append(out, l)
	}
	return out
}

// LiabilityDebits are the liability accounts j debits on net. The poster
// locks them and refuses a posting that would leave one in debit
// (invariant 3). Asset and revenue accounts are never locked.
func (j Journal) LiabilityDebits() []Line {
	var out []Line
	for _, l := range j.NetByAccount() {
		if l.Account.Type == Liability && l.Amount > 0 {
			out = append(out, l)
		}
	}
	return out
}

package domain

import (
	"fmt"

	"github.com/google/uuid"
)

// ErrAllocationsExceedPayment: a capture's allocations sum to more than the payment.
var ErrAllocationsExceedPayment = fmt.Errorf("%w: allocations exceed the payment amount", ErrInvalidPosting)

// Allocation is one order's share of a captured payment. It is written once
// with CAPTURE (escrow_allocations) and is what RELEASE and REFUND move.
type Allocation struct {
	OrderID      uuid.UUID
	PaymentID    uuid.UUID
	CheckoutID   uuid.UUID
	SellerUserID uuid.UUID
	Amount       int64 // the order total held in escrow
	Commission   int64 // the platform's cut, 0 ≤ Commission < Amount
	Provider     string
}

func (a Allocation) validate() error {
	switch {
	case a.Amount <= 0:
		return fmt.Errorf("%w: allocation amount %d must be positive", ErrInvalidPosting, a.Amount)
	case a.Commission < 0 || a.Commission >= a.Amount:
		return fmt.Errorf("%w: commission %d must be in [0, %d)", ErrInvalidPosting, a.Commission, a.Amount)
	case !ValidProvider(a.Provider):
		return fmt.Errorf("%w: unknown provider %q", ErrInvalidPosting, a.Provider)
	}
	return nil
}

func positive(amount int64) error {
	if amount <= 0 {
		return fmt.Errorf("%w: amount %d must be positive", ErrInvalidPosting, amount)
	}
	return nil
}

func knownProvider(p string) error {
	if !ValidProvider(p) {
		return fmt.Errorf("%w: unknown provider %q", ErrInvalidPosting, p)
	}
	return nil
}

// Pay records a provider charge into the checkout's suspense account.
func Pay(paymentID, checkoutID uuid.UUID, provider string, amount int64) (Journal, error) {
	if err := positive(amount); err != nil {
		return Journal{}, err
	}
	if err := knownProvider(provider); err != nil {
		return Journal{}, err
	}
	return Journal{
		Key: "pay:" + paymentID.String(), Kind: KindPay,
		Refs: Refs{CheckoutID: &checkoutID, PaymentID: &paymentID},
		Lines: []Line{
			{Account: PSPClearing(provider), Amount: amount},
			{Account: CheckoutSuspense(checkoutID), Amount: -amount},
		},
	}, nil
}

// Capture moves the allocated part of a payment from suspense into each
// order's escrow. Allocations must belong to this payment, name distinct
// orders and not exceed paymentAmount.
func Capture(paymentID, checkoutID uuid.UUID, paymentAmount int64, allocs []Allocation) (Journal, error) {
	if len(allocs) == 0 {
		return Journal{}, fmt.Errorf("%w: capture without allocations", ErrInvalidPosting)
	}
	seen := map[uuid.UUID]bool{}
	var total int64
	lines := make([]Line, 1, len(allocs)+1) // lines[0] is the suspense debit, set below
	for _, a := range allocs {
		if err := a.validate(); err != nil {
			return Journal{}, err
		}
		if a.PaymentID != paymentID || a.CheckoutID != checkoutID {
			return Journal{}, fmt.Errorf("%w: allocation for order %s belongs to another payment", ErrInvalidPosting, a.OrderID)
		}
		if seen[a.OrderID] {
			return Journal{}, fmt.Errorf("%w: order %s allocated twice", ErrInvalidPosting, a.OrderID)
		}
		seen[a.OrderID] = true
		total += a.Amount
		lines = append(lines, Line{Account: Escrow(a.OrderID, a.SellerUserID), Amount: -a.Amount})
	}
	if total > paymentAmount {
		return Journal{}, fmt.Errorf("%w: %d > %d", ErrAllocationsExceedPayment, total, paymentAmount)
	}
	lines[0] = Line{Account: CheckoutSuspense(checkoutID), Amount: total}
	return Journal{
		Key: "capture:" + paymentID.String(), Kind: KindCapture,
		Refs: Refs{CheckoutID: &checkoutID, PaymentID: &paymentID}, Lines: lines,
	}, nil
}

// Release pays a completed order's escrow to the seller wallet, less the
// commission. The commission line is omitted when the commission is 0.
func Release(a Allocation) (Journal, error) {
	if err := a.validate(); err != nil {
		return Journal{}, err
	}
	lines := []Line{
		{Account: Escrow(a.OrderID, a.SellerUserID), Amount: a.Amount},
		{Account: SellerWallet(a.SellerUserID), Amount: -(a.Amount - a.Commission)},
	}
	if a.Commission > 0 {
		lines = append(lines, Line{Account: CommissionRevenue(), Amount: -a.Commission})
	}
	return Journal{
		Key: "release:" + a.OrderID.String(), Kind: KindRelease,
		Refs:  Refs{CheckoutID: &a.CheckoutID, PaymentID: &a.PaymentID, OrderID: &a.OrderID},
		Lines: lines,
	}, nil
}

// Refund returns a cancelled order's escrow to the provider.
func Refund(refundID uuid.UUID, a Allocation) (Journal, error) {
	if err := a.validate(); err != nil {
		return Journal{}, err
	}
	return Journal{
		Key: "refund:" + refundID.String(), Kind: KindRefund,
		Refs: Refs{CheckoutID: &a.CheckoutID, PaymentID: &a.PaymentID, OrderID: &a.OrderID, RefundID: &refundID},
		Lines: []Line{
			{Account: Escrow(a.OrderID, a.SellerUserID), Amount: a.Amount},
			{Account: PSPClearing(a.Provider), Amount: -a.Amount},
		},
	}, nil
}

// DuplicateRefund returns a duplicate charge from the checkout's suspense.
func DuplicateRefund(refundID, paymentID, checkoutID uuid.UUID, provider string, amount int64) (Journal, error) {
	if err := positive(amount); err != nil {
		return Journal{}, err
	}
	if err := knownProvider(provider); err != nil {
		return Journal{}, err
	}
	return Journal{
		Key: "refund:" + refundID.String(), Kind: KindDuplicateRefund,
		Refs: Refs{CheckoutID: &checkoutID, PaymentID: &paymentID, RefundID: &refundID},
		Lines: []Line{
			{Account: CheckoutSuspense(checkoutID), Amount: amount},
			{Account: PSPClearing(provider), Amount: -amount},
		},
	}, nil
}

        tx_id := NEW.id;
    END IF;
    SELECT count(*), coalesce(sum(amount), 0) INTO n, total FROM entries WHERE transaction_id = tx_id;
    IF n < 2 THEN
        RAISE EXCEPTION 'ledger: transaction % has % entries (at least 2 required)', tx_id, n
            USING ERRCODE = 'check_violation';
    END IF;
    IF total <> 0 THEN
        RAISE EXCEPTION 'ledger: transaction % is unbalanced (sum %)', tx_id, total
            USING ERRCODE = 'check_violation';
    END IF;
    RETURN NULL;
END
$$;

CREATE CONSTRAINT TRIGGER entries_balanced AFTER INSERT ON entries
    DEFERRABLE INITIALLY DEFERRED FOR EACH ROW EXECUTE FUNCTION ledger_check_transaction_balanced();
CREATE CONSTRAINT TRIGGER journal_transactions_have_entries AFTER INSERT ON journal_transactions
    DEFERRABLE INITIALLY DEFERRED FOR EACH ROW EXECUTE FUNCTION ledger_check_transaction_balanced();

-- Invariant 3 backstop: no liability account ends a transaction in debit.
-- The posting engine checks first under FOR UPDATE (that lock is what makes
-- concurrent debits correct); this catches any other writer.
CREATE FUNCTION ledger_check_liability_not_in_debit() RETURNS trigger LANGUAGE plpgsql AS $$
DECLARE
    acc_type text;
    balance  numeric;
BEGIN
    SELECT type INTO acc_type FROM accounts WHERE id = NEW.account_id;
    IF acc_type = 'liability' THEN
        SELECT coalesce(sum(amount), 0) INTO balance FROM entries WHERE account_id = NEW.account_id;
        IF balance > 0 THEN
            RAISE EXCEPTION 'ledger: liability account % would be in debit (%)', NEW.account_id, balance
                USING ERRCODE = 'check_violation';
        END IF;
    END IF;
    RETURN NULL;
END
$$;

CREATE CONSTRAINT TRIGGER entries_liability_not_in_debit AFTER INSERT ON entries
    DEFERRABLE INITIALLY DEFERRED FOR EACH ROW EXECUTE FUNCTION ledger_check_liability_not_in_debit();

package app

import (
	"context"
	"errors"
	"fmt"
	"slices"
	"time"

	"github.com/google/uuid"

	"github.com/ngoxuanchien/e-commerce/services/ledger/internal/domain"
)

// ErrWouldOverdraw: the posting would leave a liability account in debit (invariant 3).
var ErrWouldOverdraw = errors.New("ledger: posting would put a liability account into debit")

// OverdrawError details ErrWouldOverdraw. Balance is the account's Σ before
// the posting; Debit is the posting's net debit to it.
type OverdrawError struct {
	Account string
	Balance int64
	Debit   int64
}

func (e *OverdrawError) Error() string {
	return fmt.Sprintf("%s: %s has balance %d, debit %d", ErrWouldOverdraw, e.Account, e.Balance, e.Debit)
}

func (e *OverdrawError) Is(target error) bool { return target == ErrWouldOverdraw }

// PostResult is the posted transaction. Replayed: its key was already
// posted, and nothing new was written.
type PostResult struct {
	TransactionID uuid.UUID
	Replayed      bool
}

// Post applies j inside the caller's transaction (WS2' §4):
//  1. validate j (Σ = 0, at least 2 lines);
//  2. create its accounts and lock the liability accounts it debits, in id order;
//  3. if its idempotency key was already posted, return that transaction;
//  4. refuse it if a locked account would end in debit;
//  5. insert it. A concurrent poster of the same key that committed first
//     turns this into a replay.
func Post(ctx context.Context, l Ledger, j domain.Journal) (PostResult, error) {
	if err := j.Validate(); err != nil {
		return PostResult{}, err
	}
	if j.OccurredAt.IsZero() {
		j.OccurredAt = time.Now().UTC()
	}
	accounts := make([]domain.Account, len(j.Lines))
	for i, line := range j.Lines {
		accounts[i] = line.Account
	}
	ids, err := l.EnsureAccounts(ctx, accounts)
	if err != nil {
		return PostResult{}, err
	}
	debits := j.LiabilityDebits()
	lock := make([]uuid.UUID, 0, len(debits))
	for _, d := range debits {
		lock = append(lock, ids[d.Account.Code])
	}
	slices.SortFunc(lock, func(a, b uuid.UUID) int { return slices.Compare(a[:], b[:]) })
	if err := l.LockAccounts(ctx, lock); err != nil {
		return PostResult{}, err
	}
	if id, found, err := l.TransactionIDByKey(ctx, j.Key); err != nil {
		return PostResult{}, err
	} else if found {
		return PostResult{TransactionID: id, Replayed: true}, nil
	}
	for _, d := range debits {
		bal, err := l.Balance(ctx, ids[d.Account.Code])
		if err != nil {
			return PostResult{}, err
		}
		if bal+d.Amount > 0 {
			return PostResult{}, &OverdrawError{Account: d.Account.Code, Balance: bal, Debit: d.Amount}
		}
	}
	id := uuid.Must(uuid.NewV7())
	inserted, err := l.InsertJournal(ctx, id, j, ids)
	if err != nil {
		return PostResult{}, err
	}
	if !inserted {
		existing, found, err := l.TransactionIDByKey(ctx, j.Key)
		if err != nil {
			return PostResult{}, err
		}
		if !found {
			return PostResult{}, fmt.Errorf("ledger: key %s conflicted but no transaction was found", j.Key)
		}
		return PostResult{TransactionID: existing, Replayed: true}, nil
	}
	return PostResult{TransactionID: id}, nil
}

package postgres

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"

	"github.com/ngoxuanchien/e-commerce/services/ledger/internal/adapter/postgres/sqlcdb"
	"github.com/ngoxuanchien/e-commerce/services/ledger/internal/app"
	"github.com/ngoxuanchien/e-commerce/services/ledger/internal/domain"
)

// txStore implements app.Tx inside one database transaction.
type txStore struct {
	tx pgx.Tx
	q  *sqlcdb.Queries
}

var _ app.Tx = (*txStore)(nil)

func newUUID() uuid.UUID { return uuid.Must(uuid.NewV7()) }

func (t *txStore) EnsureAccounts(ctx context.Context, accounts []domain.Account) (map[string]uuid.UUID, error) {
	codes := make([]string, 0, len(accounts))
	seen := map[string]bool{}
	for _, a := range accounts {
		if seen[a.Code] {
			continue
		}
		seen[a.Code] = true
		codes = append(codes, a.Code)
		if err := t.q.EnsureAccount(ctx, sqlcdb.EnsureAccountParams{
			ID: newUUID(), Code: a.Code, Type: string(a.Type), OwnerUserID: a.OwnerID, OrderID: a.OrderID,
		}); err != nil {
			return nil, fmt.Errorf("ensure account %s: %w", a.Code, err)
		}
	}
	rows, err := t.q.AccountIDsByCode(ctx, codes)
	if err != nil {
		return nil, fmt.Errorf("account ids: %w", err)
	}
	ids := make(map[string]uuid.UUID, len(rows))
	for _, r := range rows {
		ids[r.Code] = r.ID
	}
	if len(ids) != len(codes) {
		return nil, fmt.Errorf("account ids: found %d of %d accounts", len(ids), len(codes))
	}
	return ids, nil
}

func (t *txStore) LockAccounts(ctx context.Context, ids []uuid.UUID) error {
	if len(ids) == 0 {
		return nil
	}
	if _, err := t.q.LockAccounts(ctx, ids); err != nil {
		return fmt.Errorf("lock accounts: %w", err)
	}
	return nil
}

func (t *txStore) Balance(ctx context.Context, accountID uuid.UUID) (int64, error) {
	b, err := t.q.AccountBalance(ctx, accountID)
	if err != nil {
		return 0, fmt.Errorf("account balance: %w", err)
	}
	return b, nil
}

func (t *txStore) TransactionIDByKey(ctx context.Context, key string) (uuid.UUID, bool, error) {
	id, err := t.q.TransactionIDByKey(ctx, key)
	if errors.Is(err, pgx.ErrNoRows) {
		return uuid.Nil, false, nil
	}
	if err != nil {
		return uuid.Nil, false, fmt.Errorf("transaction by key: %w", err)
	}
	return id, true, nil
}

func (t *txStore) InsertJournal(ctx context.Context, id uuid.UUID, j domain.Journal, accountIDs map[string]uuid.UUID) (bool, error) {
	refs, err := json.Marshal(j.Refs)
	if err != nil {
		return false, fmt.Errorf("encode refs: %w", err)
	}
	n, err := t.q.InsertTransaction(ctx, sqlcdb.InsertTransactionParams{
		ID: id, IdempotencyKey: j.Key, Kind: string(j.Kind), Refs: refs,
		SourceEventID: j.SourceEventID, OccurredAt: j.OccurredAt,
	})
	if err != nil {
		return false, fmt.Errorf("insert transaction: %w", err)
	}
	if n == 0 {
		return false, nil
	}
	for _, l := range j.Lines {
		if err := t.q.InsertEntry(ctx, sqlcdb.InsertEntryParams{
			ID: newUUID(), TransactionID: id, AccountID: accountIDs[l.Account.Code], Amount: l.Amount,
		}); err != nil {
			return false, fmt.Errorf("insert entry: %w", err)
		}
	}
	return true, nil
}

	ClaimPending(ctx context.Context, limit int) ([]PendingPosting, error)

	// TouchPending counts one more attempt at `at`.
	TouchPending(ctx context.Context, orderID uuid.UUID, at time.Time) error
}

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"log/slog"
	"time"

// ConsumerName is ledger-svc's consumer group and processed_events consumer.
const ConsumerName = "ledger-svc"

var (
	// ErrInvalidEvent: the event can never be applied (bad ids, undecodable data).
	ErrInvalidEvent = errors.New("ledger: invalid event")
	// ErrAllocationMissing: a refund arrived before its capture. Retryable.
	ErrAllocationMissing = errors.New("ledger: no escrow allocation for the order yet")
)

// EventHandler applies payment.events and order.events to the ledger (WS2' §6).
type EventHandler struct {
	store  Store
	logger *slog.Logger
	now    func() time.Time
}

func NewEventHandler(store Store, logger *slog.Logger, now func() time.Time) *EventHandler {
	return &EventHandler{store: store, logger: logger, now: now}
}

// source is the event a posting comes from.
type source struct {
	eventID    uuid.UUID
	occurredAt time.Time
}

func (s source) stamp(j domain.Journal) domain.Journal {
	j.SourceEventID = &s.eventID
	j.OccurredAt = s.occurredAt
	return j
}

type applyFunc func(ctx context.Context, tx Tx, src source) error

// Handle applies one event in one database transaction: processed_events,
// then the postings. It returns nil when the event is done, a duplicate, not
// a ledger event, or can never be applied (logged and skipped, so it cannot
// block its partition). Other errors are returned so the consumer retries.
func (h *EventHandler) Handle(ctx context.Context, env event.Envelope) error {
	var apply applyFunc
	var err error
	switch env.EventType {
	case event.TypePaymentSucceeded:
		apply, err = bind(env, h.paymentSucceeded)
	case event.TypeOrderCompleted:
		apply, err = bind(env, func(ctx context.Context, tx Tx, src source, d event.OrderCompleted) error {
			return h.orderCompleted(ctx, tx, src, env, d)
		})
	case event.TypePaymentRefunded:
		apply, err = bind(env, h.paymentRefunded)
	default:
		return nil
	}
	eventID, idErr := uuid.Parse(env.EventID)
	if err == nil && idErr != nil {
		err = fmt.Errorf("%w: event_id %q", ErrInvalidEvent, env.EventID)
	}
	if err != nil {
		h.skip(ctx, env, err)
		return nil
	}
	src := source{eventID: eventID, occurredAt: env.OccurredAt.UTC()}
	err = h.store.InTx(ctx, func(tx Tx) error {
		first, err := tx.MarkProcessed(ctx, eventID)
		if err != nil || !first {
			return err
		}
		return apply(ctx, tx, src)
	})
	if err != nil && permanent(err) {
		h.skip(ctx, env, err)
		return nil
	}
	return err
}

func bind[T event.Payload](env event.Envelope, fn func(context.Context, Tx, source, T) error) (applyFunc, error) {
	d, err := event.DecodeData[T](env)
	if err != nil {
		return nil, fmt.Errorf("%w: %w", ErrInvalidEvent, err)
	}
	return func(ctx context.Context, tx Tx, src source) error { return fn(ctx, tx, src, d) }, nil
}

// permanent reports errors that no retry can fix.
func permanent(err error) bool {
	return errors.Is(err, ErrInvalidEvent) || errors.Is(err, ErrWouldOverdraw) ||
		errors.Is(err, domain.ErrInvalidPosting) || errors.Is(err, domain.ErrTooFewLines) ||
		errors.Is(err, domain.ErrZeroLine) || errors.Is(err, domain.ErrUnbalanced)
}

func (h *EventHandler) skip(ctx context.Context, env event.Envelope, err error) {
	h.logger.ErrorContext(ctx, "ledger skipped an event it can never apply",
		"alert", errors.Is(err, ErrWouldOverdraw), "event_id", env.EventID, "event_type", env.EventType, "error", err)
}

func parseID(field, s string) (uuid.UUID, error) {
	u, err := uuid.Parse(s)
	if err != nil {
		return uuid.Nil, fmt.Errorf("%w: %s %q", ErrInvalidEvent, field, s)
	}
	return u, nil
}

func (h *EventHandler) paymentSucceeded(ctx context.Context, tx Tx, src source, d event.PaymentSucceeded) error {
	paymentID, err := parseID("payment_id", d.PaymentID)
	if err != nil {
		return err
	}
	checkoutID, err := parseID("checkout_id", d.CheckoutID)
	if err != nil {
		return err
	}
	pay, err := domain.Pay(paymentID, checkoutID, d.Provider, d.Amount)
	if err != nil {
		return err
	}
	if _, err := Post(ctx, tx, src.stamp(pay)); err != nil {
		return err
	}
	if len(d.Allocations) == 0 {
		return nil // a duplicate charge: it waits in suspense for its refund
	}
	allocs := make([]domain.Allocation, 0, len(d.Allocations))
	for _, a := range d.Allocations {
		orderID, err := parseID("allocations.order_id", a.OrderID)
		if err != nil {
			return err
		}
		sellerID, err := parseID("allocations.seller_user_id", a.SellerUserID)
		if err != nil {
			return err
		}
		allocs = append(allocs, domain.Allocation{OrderID: orderID, PaymentID: paymentID, CheckoutID: checkoutID,
			SellerUserID: sellerID, Amount: a.Amount, Commission: a.CommissionAmount, Provider: d.Provider})
	}
	capture, err := domain.Capture(paymentID, checkoutID, d.Amount, allocs)
	if err != nil {
		return err
	}
	for _, a := range allocs {
		existing, found, err := tx.GetAllocation(ctx, a.OrderID)
		if err != nil {
			return err
		}
		if found && existing.PaymentID != paymentID {
			h.logger.ErrorContext(ctx, "order already captured by another payment; this payment stays in suspense",
				"alert", true, "order_id", a.OrderID, "payment_id", paymentID, "captured_by", existing.PaymentID)
			return nil
		}
	}
	for _, a := range allocs {
		if err := tx.InsertAllocation(ctx, a); err != nil {
			return err
		}
	}
	if _, err := Post(ctx, tx, src.stamp(capture)); err != nil {
		return err
	}
	return h.applyPending(ctx, tx, allocs)
}

// applyPending releases the orders whose OrderCompleted arrived before this capture.
func (h *EventHandler) applyPending(ctx context.Context, tx Tx, allocs []domain.Allocation) error {
	byOrder := make(map[uuid.UUID]domain.Allocation, len(allocs))
	ids := make([]uuid.UUID, 0, len(allocs))
	for _, a := range allocs {
		byOrder[a.OrderID] = a
		ids = append(ids, a.OrderID)
	}
	rows, err := tx.TakePending(ctx, ids)
	if err != nil {
		return err
	}
	for _, r := range rows {
		src, d, err := decodePending(r)
		if err != nil {
			h.logger.ErrorContext(ctx, "dropping an undecodable pending posting", "order_id", r.OrderID, "error", err)
		} else if err := h.release(ctx, tx, src, byOrder[r.OrderID], d); err != nil {
			return err
		}
		if err := tx.DeletePending(ctx, r.OrderID); err != nil {
			return err
		}
	}
	return nil
}

func decodePending(r PendingPosting) (source, event.OrderCompleted, error) {
	env, err := event.Decode(r.Envelope)
	if err != nil {
		return source{}, event.OrderCompleted{}, err
	}
	d, err := event.DecodeData[event.OrderCompleted](env)
	if err != nil {
		return source{}, event.OrderCompleted{}, err
	}
	id, err := parseID("event_id", env.EventID)
	if err != nil {
		return source{}, event.OrderCompleted{}, err
	}
	return source{eventID: id, occurredAt: env.OccurredAt.UTC()}, d, nil
}

func (h *EventHandler) orderCompleted(ctx context.Context, tx Tx, src source, env event.Envelope, d event.OrderCompleted) error {
	if d.PaymentMethod == "" || d.PaymentMethod == event.PaymentMethodCOD {
		return nil // COD never enters the ledger
	}
	orderID, err := parseID("order_id", d.OrderID)
	if err != nil {
		return err
	}
	a, found, err := tx.GetAllocation(ctx, orderID)
	if err != nil {
		return err
	}
	if !found { // PaymentSucceeded travels on another topic and hasn't arrived yet
		raw, err := json.Marshal(env)
		if err != nil {
			return err
		}
		return tx.InsertPending(ctx, orderID, raw, h.now())
	}
	return h.release(ctx, tx, src, a, d)
}

// release posts RELEASE from the allocation, which is what was captured.
func (h *EventHandler) release(ctx context.Context, tx Tx, src source, a domain.Allocation, d event.OrderCompleted) error {
	if d.Total != a.Amount || d.CommissionAmount != a.Commission {
		h.logger.ErrorContext(ctx, "OrderCompleted amounts differ from the captured allocation; releasing the allocation",
			"order_id", a.OrderID, "event_total", d.Total, "event_commission", d.CommissionAmount,
			"allocation_amount", a.Amount, "allocation_commission", a.Commission)
	}
	j, err := domain.Release(a)
	if err != nil {
		return err
	}
	_, err = Post(ctx, tx, src.stamp(j))
	return err
}

func (h *EventHandler) paymentRefunded(ctx context.Context, tx Tx, src source, d event.PaymentRefunded) error {
	refundID, err := parseID("refund_id", d.RefundID)
	if err != nil {
		return err
	}
	paymentID, err := parseID("payment_id", d.PaymentID)
	if err != nil {
		return err
	}
	checkoutID, err := parseID("checkout_id", d.CheckoutID)
	if err != nil {
		return err
	}
	if d.OrderID == nil {
		j, err := domain.DuplicateRefund(refundID, paymentID, checkoutID, d.Provider, d.Amount)
		if err != nil {
			return err
		}
		_, err = Post(ctx, tx, src.stamp(j))
		return err
	}
	orderID, err := parseID("order_id", *d.OrderID)
	if err != nil {
		return err
	}
	a, found, err := tx.GetAllocation(ctx, orderID)
	if err != nil {
		return err
	}
	if !found {
		return fmt.Errorf("%w: order %s", ErrAllocationMissing, orderID)
	}
	if d.Amount != a.Amount || d.Provider != a.Provider {
		h.logger.ErrorContext(ctx, "PaymentRefunded differs from the captured allocation; refunding the allocation",
			"order_id", orderID, "event_amount", d.Amount, "event_provider", d.Provider,
			"allocation_amount", a.Amount, "allocation_provider", a.Provider)
	}
	j, err := domain.Refund(refundID, a)
	if err != nil {
		return err
	}
	_, err = Post(ctx, tx, src.stamp(j))
	return err
}

```go
package app

import (
	"context"
	"log/slog"
	"time"
)

// PendingConfig tunes PendingJob. Zero StaleAfter = 1h, zero BatchSize = 50.
type PendingConfig struct {
	Interval   time.Duration // PENDING_POSTING_INTERVAL
	StaleAfter time.Duration
	BatchSize  int
	Now        func() time.Time
	Logger     *slog.Logger
}

// PendingJob retries OrderCompleted events parked before their capture
// (WS2' §6). Rows are claimed with SKIP LOCKED, so replicas don't collide.
type PendingJob struct {
	store  Store
	events *EventHandler
	cfg    PendingConfig
}

func NewPendingJob(store Store, events *EventHandler, cfg PendingConfig) *PendingJob {
	if cfg.StaleAfter == 0 {
		cfg.StaleAfter = time.Hour
	}
	if cfg.BatchSize == 0 {
		cfg.BatchSize = 50
	}
	return &PendingJob{store: store, events: events, cfg: cfg}
}

// Run calls RunOnce every Interval until ctx is cancelled.
func (j *PendingJob) Run(ctx context.Context) error {
	for {
		if _, err := j.RunOnce(ctx); err != nil && ctx.Err() == nil {
			j.cfg.Logger.ErrorContext(ctx, "pending postings run failed", "error", err)
		}
		select {
		case <-ctx.Done():
			return nil
		case <-time.After(j.cfg.Interval):
		}
	}
}

// RunOnce releases every claimed row whose allocation now exists and counts
// an attempt on the rest. It returns how many orders were released.
func (j *PendingJob) RunOnce(ctx context.Context) (int, error) {
	var released int
	err := j.store.InTx(ctx, func(tx Tx) error {
		released = 0
		rows, err := tx.ClaimPending(ctx, j.cfg.BatchSize)
		if err != nil {
			return err
		}
		now := j.cfg.Now()
		for _, r := range rows {
			src, d, err := decodePending(r)
			if err != nil {
				j.cfg.Logger.ErrorContext(ctx, "dropping an undecodable pending posting", "order_id", r.OrderID, "error", err)
				if err := tx.DeletePending(ctx, r.OrderID); err != nil {
					return err
				}
				continue
			}
			a, found, err := tx.GetAllocation(ctx, r.OrderID)
			if err != nil {
				return err
			}
			if !found {
				if now.Sub(r.CreatedAt) > j.cfg.StaleAfter {
					j.cfg.Logger.ErrorContext(ctx, "pending posting still waiting for its capture",
						"order_id", r.OrderID, "since", r.CreatedAt, "attempts", r.Attempts+1)
				}
				if err := tx.TouchPending(ctx, r.OrderID, now); err != nil {
					return err
				}
				continue
			}
			if err := j.events.release(ctx, tx, src, a, d); err != nil {
				if !permanent(err) {
					return err
				}
				j.cfg.Logger.ErrorContext(ctx, "pending release rejected", "alert", true, "order_id", r.OrderID, "error", err)
				if err := tx.TouchPending(ctx, r.OrderID, now); err != nil {
					return err
				}
				continue
			}
			if err := tx.DeletePending(ctx, r.OrderID); err != nil {
				return err
			}
			released++
		}
		return nil
	})
	return released, err
}
```

// Response is a rendered HTTP response, stored for Idempotency-Key replays.
type Response = idemkey.Response

// PayoutEncoder renders a payout result: the created payout (err nil) or a
// deterministic rejection (*InsufficientFundsError). The HTTP adapter owns it.
type PayoutEncoder func(p domain.Payout, err error) Response

const payoutScope = "payout"

var (
	ErrIdempotencyKeyReused  = errors.New("ledger: idempotency key reused with a different request")
	ErrIdempotencyInProgress = errors.New("ledger: a request with this idempotency key is in progress")
)

// BelowMinimumError: the amount is below PAYOUT_MIN_AMOUNT.
type BelowMinimumError struct{ Min int64 }

func (e *BelowMinimumError) Error() string { return fmt.Sprintf("payout amount must be at least %d", e.Min) }

// InsufficientFundsError: the wallet's available balance is below the amount.
type InsufficientFundsError struct{ Available int64 }

func (e *InsufficientFundsError) Error() string {
	return fmt.Sprintf("insufficient funds: %d available", e.Available)
}

// PayoutConfig tunes PayoutService. Zero ClaimTimeout = 1 minute.
type PayoutConfig struct {
	MinAmount    int64 // PAYOUT_MIN_AMOUNT
	ClaimTimeout time.Duration
	Now          func() time.Time
	Logger       *slog.Logger
}

// PayoutService handles payout requests (WS2' §7).
type PayoutService struct {
	store Store
	cfg   PayoutConfig
}

func NewPayoutService(store Store, cfg PayoutConfig) *PayoutService {
	if cfg.ClaimTimeout == 0 {
		cfg.ClaimTimeout = time.Minute
	}
	return &PayoutService{store: store, cfg: cfg}
}

// PayoutRequestInput is one POST /api/seller/payouts.
type PayoutRequestInput struct {
	SellerID       uuid.UUID
	IdempotencyKey string
	Amount         int64
}

// Request moves Amount from the seller's wallet to payout-pending, or answers
// INSUFFICIENT_FUNDS. Both outcomes are stored under the Idempotency-Key and
// replayed verbatim; transient failures free the key and return an error.
func (s *PayoutService) Request(ctx context.Context, in PayoutRequestInput, enc PayoutEncoder) (Response, error) {
	if in.Amount < s.cfg.MinAmount {
		return Response{}, &BelowMinimumError{Min: s.cfg.MinAmount}
	}
	hash := sha256.Sum256([]byte(strconv.FormatInt(in.Amount, 10)))
	now := s.cfg.Now()
	rec, claimed, err := s.store.ClaimKey(ctx, payoutScope, in.SellerID, in.IdempotencyKey, hash[:], now, now.Add(-s.cfg.ClaimTimeout))
	if err != nil {
		return Response{}, err
	}
	if !claimed {
		switch {
		case !bytes.Equal(rec.RequestHash, hash[:]):
			return Response{}, ErrIdempotencyKeyReused
		case rec.Response == nil:
			return Response{}, ErrIdempotencyInProgress
		default:
			return *rec.Response, nil
		}
	}
	resp, err := s.request(ctx, in, rec.ClaimedAt, enc)
	if err == nil {
		return resp, nil
	}
	if errors.Is(err, idemkey.ErrClaimLost) {
		return Response{}, ErrIdempotencyInProgress
	}
	if rerr := s.store.ReleaseKey(context.WithoutCancel(ctx), payoutScope, in.SellerID, in.IdempotencyKey, rec.ClaimedAt); rerr != nil {
		s.cfg.Logger.ErrorContext(ctx, "release payout idempotency key", "error", rerr)
	}
	return Response{}, err
}

func (s *PayoutService) request(ctx context.Context, in PayoutRequestInput, claimedAt time.Time, enc PayoutEncoder) (Response, error) {
	now := s.cfg.Now()
	p := domain.Payout{ID: uuid.Must(uuid.NewV7()), SellerUserID: in.SellerID, Amount: in.Amount,
		Status: domain.PayoutRequested, RequestedAt: now, Version: 1}
	j, err := domain.PayoutRequest(p)
	if err != nil {
		return Response{}, err
	}
	j.OccurredAt = now
	var resp Response
	err = s.store.InTx(ctx, func(tx Tx) error {
		_, err := Post(ctx, tx, j) // locks the wallet and checks available ≥ amount
		var oe *OverdrawError
		switch {
		case errors.As(err, &oe):
			resp = enc(domain.Payout{}, &InsufficientFundsError{Available: domain.Shown(oe.Balance)})
		case err != nil:
			return err
		default:
			if err := tx.InsertPayout(ctx, p); err != nil {
				return err
			}
			ev := event.PayoutRequested{PayoutID: p.ID.String(), SellerUserID: p.SellerUserID.String(), Amount: p.Amount}
			if err := tx.PublishPayoutEvent(ctx, p.SellerUserID, ev, now); err != nil {
				return err
			}
			resp = enc(p, nil)
		}
		return tx.CompleteKey(ctx, payoutScope, in.SellerID, in.IdempotencyKey, claimedAt, resp)
	})
	return resp, err
}

// Bank transfers a payout to the seller. Transfer must be idempotent per
// payoutID: a crash after it succeeds but before the settle transaction
// commits repeats the call on the next run.
type Bank interface {
	Transfer(ctx context.Context, payoutID, sellerID uuid.UUID, amount int64) error
}

// TransferRejectedError is a final refusal; other Bank errors are retried.
type TransferRejectedError struct{ Reason string }

func (e *TransferRejectedError) Error() string { return "bank rejected the transfer: " + e.Reason }

// SettleConfig tunes SettleJob. Zero BatchSize = 20.
type SettleConfig struct {
	Interval  time.Duration // PAYOUT_SETTLE_INTERVAL
	Delay     time.Duration // PAYOUT_SETTLE_DELAY
	BatchSize int
	Now       func() time.Time
	Logger    *slog.Logger
}

// SettleJob settles REQUESTED payouts older than Delay (WS2' §7).
type SettleJob struct {
	store Store
	bank  Bank
	cfg   SettleConfig
}

func NewSettleJob(store Store, bank Bank, cfg SettleConfig) *SettleJob {
	if cfg.BatchSize == 0 {
		cfg.BatchSize = 20
	}
	return &SettleJob{store: store, bank: bank, cfg: cfg}
}

// Run calls RunOnce every Interval until ctx is cancelled.
func (j *SettleJob) Run(ctx context.Context) error {
	for {
		if _, err := j.RunOnce(ctx); err != nil && ctx.Err() == nil {
			j.cfg.Logger.ErrorContext(ctx, "payout settle run failed", "error", err)
		}
		select {
		case <-ctx.Done():
			return nil
		case <-time.After(j.cfg.Interval):
		}
	}
}

// RunOnce settles up to BatchSize due payouts, one transaction each, and
// returns how many were settled or failed. It stops at the first error.
func (j *SettleJob) RunOnce(ctx context.Context) (int, error) {
	n := 0
	for n < j.cfg.BatchSize {
		done, err := j.settleOne(ctx)
		if err != nil {
			return n, err
		}
		if !done {
			break
		}
		n++
	}
	return n, nil
}

func (j *SettleJob) settleOne(ctx context.Context) (bool, error) {
	var found bool
	err := j.store.InTx(ctx, func(tx Tx) error {
		now := j.cfg.Now()
		p, ok, err := tx.ClaimDuePayout(ctx, now.Add(-j.cfg.Delay))
		if err != nil || !ok {
			return err
		}
		found = true
		prev := p.Version
		var journal domain.Journal
		var ev event.Payload
		terr := j.bank.Transfer(ctx, p.ID, p.SellerUserID, p.Amount)
		var rejected *TransferRejectedError
		switch {
		case terr == nil:
			p.Status, p.SettledAt = domain.PayoutSettled, &now
			journal, err = domain.PayoutSettle(p)
			ev = event.PayoutSettled{PayoutID: p.ID.String(), SellerUserID: p.SellerUserID.String(), Amount: p.Amount, SettledAt: now}
		case errors.As(terr, &rejected):
			reason := rejected.Reason
			p.Status, p.FailureReason = domain.PayoutFailed, &reason
			journal, err = domain.PayoutFail(p)
			ev = event.PayoutFailed{PayoutID: p.ID.String(), SellerUserID: p.SellerUserID.String(), Amount: p.Amount, Reason: reason}
		default:
			return fmt.Errorf("transfer payout %s: %w", p.ID, terr)
		}
		if err != nil {
			return err
		}
		journal.OccurredAt = now
		if _, err := Post(ctx, tx, journal); err != nil {
			return err
		}
		p.Version = prev + 1
		if err := tx.FinishPayout(ctx, p, prev); err != nil {
			return err
		}
		return tx.PublishPayoutEvent(ctx, p.SellerUserID, ev, now)
	})
	return found, err
}

package app

import (
	"encoding/base64"
	"errors"
	"strconv"
	"strings"
	"time"

	"github.com/google/uuid"
)

// ErrInvalidCursor: a cursor that EncodeCursor did not produce.
var ErrInvalidCursor = errors.New("ledger: invalid cursor")

// Cursor is a keyset position: (created_at | requested_at, id), newest first.
type Cursor struct {
	At time.Time
	ID uuid.UUID
}

// EncodeCursor renders c as an opaque URL-safe string.
func EncodeCursor(c Cursor) string {
	raw := strconv.FormatInt(c.At.UnixMicro(), 10) + "|" + c.ID.String()
	return base64.RawURLEncoding.EncodeToString([]byte(raw))
}

// DecodeCursor parses a string made by EncodeCursor.
func DecodeCursor(s string) (Cursor, error) {
	b, err := base64.RawURLEncoding.DecodeString(s)
	if err != nil {
		return Cursor{}, ErrInvalidCursor
	}
	ts, id, ok := strings.Cut(string(b), "|")
	if !ok {
		return Cursor{}, ErrInvalidCursor
	}
	micros, err := strconv.ParseInt(ts, 10, 64)
	if err != nil {
		return Cursor{}, ErrInvalidCursor
	}
	u, err := uuid.Parse(id)
	if err != nil {
		return Cursor{}, ErrInvalidCursor
	}
	return Cursor{At: time.UnixMicro(micros).UTC(), ID: u}, nil
}

// ListInput is a page request; Limit is already validated (1–100).
type ListInput struct {
	Limit  int
	Cursor string
}

// Page is one page of a newest-first list. Items is never nil.
type Page[T any] struct {
	Items      []T
	NextCursor *string
}

func decodeOptionalCursor(s string) (*Cursor, error) {
	if s == "" {
		return nil, nil
	}
	c, err := DecodeCursor(s)
	if err != nil {
		return nil, err
	}
	return &c, nil
}

// pageOf trims rows fetched with limit+1 and sets NextCursor when more exist.
func pageOf[T any](rows []T, limit int, key func(T) Cursor) Page[T] {
	if rows == nil {
		rows = []T{}
	}
	if len(rows) <= limit {
		return Page[T]{Items: rows}
	}
	rows = rows[:limit]
	next := EncodeCursor(key(rows[len(rows)-1]))
	return Page[T]{Items: rows, NextCursor: &next}
}

// the wallet positive.
func (s *WalletService) Entries(ctx context.Context, seller uuid.UUID, in ListInput) (Page[WalletEntry], error) {

type callerKey struct{}

// requireUUIDCaller rejects callers whose X-User-Id is not a hyphenated UUID
// and keeps the parsed id in the context.
func requireUUIDCaller(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		raw := authctx.UserID(r.Context())
		id, err := uuid.Parse(raw)
		if err != nil || len(raw) != 36 {
			httpx.WriteError(w, r, httpx.NewError(httpx.CodeUnauthenticated, "caller identity is not a valid user id"))
			return
		}
		next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), callerKey{}, id)))
	})
}

func callerID(r *http.Request) uuid.UUID { return r.Context().Value(callerKey{}).(uuid.UUID) }

// parseList reads limit and cursor, and status when withStatus.
func parseList(r *http.Request, withStatus bool) (app.ListInput, *domain.PayoutStatus, error) {
	q := r.URL.Query()
	in := app.ListInput{Limit: defaultPageLimit, Cursor: q.Get("cursor")}
	fields := map[string]string{}
	if v := q.Get("limit"); v != "" {
		n, err := strconv.Atoi(v)
		if err != nil || n < 1 || n > maxPageLimit {
			fields["limit"] = "must be an integer between 1 and 100"
		} else {
			in.Limit = n
		}
	}
	if len(in.Cursor) > maxCursorLen {
		fields["cursor"] = "is invalid"
	}
	var status *domain.PayoutStatus
	if v := q.Get("status"); withStatus && v != "" {
		st, ok := domain.ParsePayoutStatus(v)
		if !ok {
			fields["status"] = "must be one of: REQUESTED, SETTLED, FAILED"
		} else {
			status = &st
		}
	}
	if len(fields) > 0 {
		return in, nil, httpx.ValidationError(fields)
	}
	return in, status, nil
}

package httpadapter

import (
	"encoding/json"
	"errors"

	"github.com/ngoxuanchien/e-commerce/services/ledger/internal/app"

func writeError(w http.ResponseWriter, r *http.Request, err error) {
	httpx.WriteError(w, r, toAppError(err))
}

// toAppError maps use-case errors to API errors. Unknown errors pass
// through, and httpx turns them into a logged 500.
func toAppError(err error) error {
	var (
		ae  *httpx.AppError
		bm  *app.BelowMinimumError
		ife *app.InsufficientFundsError
	)
	switch {
	case errors.As(err, &ae):
		return ae
	case errors.As(err, &bm):
		return httpx.ValidationError(map[string]string{"amount": fmt.Sprintf("must be at least %d", bm.Min)})
	case errors.As(err, &ife):
		return httpx.NewError(httpx.CodeInsufficientFunds, "insufficient funds").
			WithDetails(map[string]any{"available": ife.Available})
	case errors.Is(err, app.ErrIdempotencyKeyReused):
		return httpx.NewError(httpx.CodeIdempotencyKeyReused, "Idempotency-Key was used with a different request")
	case errors.Is(err, app.ErrIdempotencyInProgress):
		return httpx.NewError(httpx.CodeConflict, "a request with this Idempotency-Key is still in progress")
	case errors.Is(err, app.ErrInvalidCursor):
		return httpx.ValidationError(map[string]string{"cursor": "is invalid"})
	}
	return err
}

type errorEnvelope struct {
	Error errorPayload `json:"error"`
}

type errorPayload struct {
	Code    string         `json:"code"`
	Message string         `json:"message"`
	Details map[string]any `json:"details,omitempty"`
}

// renderError renders a deterministic rejection for the idempotency store.
func renderError(err error) app.Response {
	var ae *httpx.AppError
	if !errors.As(toAppError(err), &ae) {

// Handler decodes records and hands them to the event handler.
type Handler struct {
	events *app.EventHandler
	logger *slog.Logger
}

func NewHandler(events *app.EventHandler, logger *slog.Logger) *Handler {
	return &Handler{events: events, logger: logger}
}

// Handle processes one record. Undecodable records are logged and skipped so
// they don't block the partition; the event handler decides the rest.
func (h *Handler) Handle(ctx context.Context, m kafkax.Message) error {
	env, err := event.Decode(m.Value)
	if err != nil {
		h.logger.WarnContext(ctx, "skipping undecodable event", "topic", m.Topic, "error", err)
		return nil
	}
	return h.events.Handle(ctx, env)
}

	return kafkax.NewConsumer(kafkax.ConsumerConfig{
		Brokers: brokers,
		Group:   GroupID,
		Topics:  []string{event.TopicPaymentEvents, event.TopicOrderEvents},
		Logger:  logger,
	}, h.Handle)

		API:    httpadapter.NewRouter(httpadapter.Services{Wallet: app.NewWalletService(store), Payouts: payouts}),
		Events: events,
		relay:  outbox.NewRelay(d.Pool, d.Producer, outbox.RelayConfig{Interval: cfg.RelayInterval, Logger: d.Logger}),
		settle: app.NewSettleJob(store, d.Bank, app.SettleConfig{
			Interval: cfg.SettleInterval, Delay: cfg.SettleDelay, Now: d.Now, Logger: d.Logger,
		}),
		pending: app.NewPendingJob(store, events, app.PendingConfig{Interval: cfg.PendingInterval, Now: d.Now, Logger: d.Logger}),
	}
	if len(cfg.Brokers) > 0 {
		c, err := kafkaadapter.NewConsumer(cfg.Brokers, kafkaadapter.NewHandler(events, d.Logger), d.Logger)
		if err != nil {
			return nil, err
		}
		a.consumer = c
	}
	return a, nil
}

// RunWorkers runs the consumer, the outbox relay, the settle job and the
// pending-postings job until ctx is cancelled, then closes the consumer.
func (a *App) RunWorkers(ctx context.Context) {
	var wg sync.WaitGroup
	run := func(f func(context.Context) error) {
		wg.Add(1)
		go func() { defer wg.Done(); _ = f(ctx) }()
	}
	run(a.relay.Run)
	run(a.settle.Run)
	run(a.pending.Run)
	if a.consumer != nil {
		run(a.consumer.Run)
	}
	wg.Wait()
	if a.consumer != nil {
		a.consumer.Close()
	}
}

import (
	"testing"

type propOrder struct {
	checkout           int
	index              int // position inside its checkout
	id, seller         uuid.UUID
	amount, commission int64
	completed          bool
	refunded           bool
}

type propDuplicate struct {
	checkout  int
	paymentID string
	refunded  bool
}

type propPayout struct {
	seller uuid.UUID
	amount int64
}

// ledgerModel is the expected state of one rapid iteration.
type ledgerModel struct {
	h           *harness
	payouts     *app.PayoutService
	sellers     []uuid.UUID
	checkouts   []checkout
	paid        []bool
	orders      []*propOrder
	duplicates  []*propDuplicate
	envelopes   []event.Envelope // everything delivered, for redelivery
	facts       []event.Payload  // everything delivered, for re-emission under a new event id
	released    map[uuid.UUID]int64
	requested   map[uuid.UUID]int64
	failed      map[uuid.UUID]int64
	outstanding []propPayout // requested, not yet settled or failed
}

func newLedgerModel(t *rapid.T, h *harness) *ledgerModel {
	m := &ledgerModel{
		h:        h,
		payouts:  app.NewPayoutService(h.store, app.PayoutConfig{MinAmount: 1, Now: h.clock.Now, Logger: h.logger}),
		sellers:  []uuid.UUID{newID(), newID()},
		released: map[uuid.UUID]int64{}, requested: map[uuid.UUID]int64{}, failed: map[uuid.UUID]int64{},
	}
	for i := range rapid.IntRange(1, 3).Draw(t, "checkouts") {
		specs := make([]orderSpec, rapid.IntRange(1, 2).Draw(t, "orders"))
		for j := range specs {
			amount := rapid.Int64Range(2, 500000).Draw(t, "amount")
			specs[j] = orderSpec{amount: amount, commission: rapid.Int64Range(0, amount-1).Draw(t, "commission"),
				seller: rapid.SampledFrom(m.sellers).Draw(t, "seller")}
		}
		c := newCheckout(rapid.SampledFrom([]string{"vnpay", "stripe", "fake"}).Draw(t, "provider"), specs...)
		m.checkouts = append(m.checkouts, c)
		m.paid = append(m.paid, false)
		for j, o := range c.orders {
			m.orders = append(m.orders, &propOrder{checkout: i, index: j, id: o.id, seller: o.seller, amount: o.amount, commission: o.commission})
		}
	}
	return m
}

func (m *ledgerModel) handle(t *rapid.T, env event.Envelope) {
	if err := m.h.events.Handle(ctx, env); err != nil {
		t.Fatalf("handle %s %s: %v", env.EventType, env.EventID, err)
	}
}

func (m *ledgerModel) deliver(t *rapid.T, p event.Payload) {
	env, err := event.New(p, m.h.clock.Now())
	if err != nil {
		t.Fatalf("new envelope: %v", err)
	}
	m.handle(t, env)
	m.envelopes = append(m.envelopes, env)
	m.facts = append(m.facts, p)
}

func (m *ledgerModel) available(s uuid.UUID) int64 { return m.released[s] - m.requested[s] + m.failed[s] }

func (m *ledgerModel) pay(t *rapid.T) {
	i := rapid.IntRange(0, len(m.checkouts)-1).Draw(t, "checkout")
	if m.paid[i] {
		t.Skip("already paid")
	}
	m.deliver(t, m.checkouts[i].succeeded())
	m.paid[i] = true
	for _, o := range m.orders {
		if o.checkout == i && o.completed { // a parked completion is released with the capture
			m.released[o.seller] += o.amount - o.commission
		}
	}
}

func (m *ledgerModel) complete(t *rapid.T) {
	o := rapid.SampledFrom(m.orders).Draw(t, "order")
	if o.completed || o.refunded {
		t.Skip("order already final")
	}
	m.deliver(t, m.checkouts[o.checkout].completed(o.index))
	o.completed = true
	if m.paid[o.checkout] {
		m.released[o.seller] += o.amount - o.commission
	}
}

func (m *ledgerModel) refund(t *rapid.T) {
	o := rapid.SampledFrom(m.orders).Draw(t, "order")
	if !m.paid[o.checkout] || o.completed || o.refunded {
		t.Skip("not refundable (ADR-0007: refund only when captured and cancelled)")
	}
	m.deliver(t, m.checkouts[o.checkout].refunded(o.index))
	o.refunded = true
}

func (m *ledgerModel) duplicate(t *rapid.T) {
	i := rapid.IntRange(0, len(m.checkouts)-1).Draw(t, "checkout")
	if !m.paid[i] {
		t.Skip("a duplicate follows the first charge")
	}
	dup := m.checkouts[i].succeeded()
	dup.PaymentID = newID().String()
	dup.Allocations = nil
	m.deliver(t, dup)
	m.duplicates = append(m.duplicates, &propDuplicate{checkout: i, paymentID: dup.PaymentID})
}

func (m *ledgerModel) refundDuplicate(t *rapid.T) {
	if len(m.duplicates) == 0 {
		t.Skip("no duplicate charge")
	}
	d := rapid.SampledFrom(m.duplicates).Draw(t, "duplicate")
	if d.refunded {
		t.Skip("already refunded")
	}
	c := m.checkouts[d.checkout]
	m.deliver(t, event.PaymentRefunded{RefundID: newID().String(), PaymentID: d.paymentID, CheckoutID: c.id.String(),
		Amount: c.amount(), Provider: c.provider})
	d.refunded = true
}

func (m *ledgerModel) redeliver(t *rapid.T) {
	if len(m.envelopes) == 0 {
		t.Skip("nothing delivered yet")
	}
	m.handle(t, rapid.SampledFrom(m.envelopes).Draw(t, "envelope"))
}

func (m *ledgerModel) reemit(t *rapid.T) {
	if len(m.facts) == 0 {
		t.Skip("nothing delivered yet")
	}
	env, err := event.New(rapid.SampledFrom(m.facts).Draw(t, "fact"), m.h.clock.Now())
	if err != nil {
		t.Fatalf("new envelope: %v", err)
	}
	m.handle(t, env)
}

func (m *ledgerModel) payout(t *rapid.T) {
	s := rapid.SampledFrom(m.sellers).Draw(t, "seller")
	amount := rapid.Int64Range(1, 600000).Draw(t, "payout")
	resp, err := m.payouts.Request(ctx, app.PayoutRequestInput{SellerID: s, IdempotencyKey: uuid.NewString(), Amount: amount}, testEncoder)
	if err != nil {
		t.Fatalf("payout request: %v", err)
	}
	if amount <= m.available(s) {
		if resp.Status != 201 {
			t.Fatalf("payout %d with %d available: status %d %s", amount, m.available(s), resp.Status, resp.Body)
		}
		m.requested[s] += amount
		m.outstanding = append(m.outstanding, propPayout{seller: s, amount: amount})
		return
	}
	if resp.Status != 409 {
		t.Fatalf("payout %d with %d available: status %d, want 409", amount, m.available(s), resp.Status)
	}
}

func (m *ledgerModel) settle(t *rapid.T) {
	reject := rapid.Bool().Draw(t, "reject")
	bank := &fakeBank{}
	if reject {
		bank.fail = func(int) error { return &app.TransferRejectedError{Reason: "rejected"} }
	}
	job := app.NewSettleJob(m.h.store, bank, app.SettleConfig{Interval: time.Second, Delay: 0, BatchSize: 10000,
		Now: m.h.clock.Now, Logger: m.h.logger})
	if _, err := job.RunOnce(ctx); err != nil {
		t.Fatalf("settle: %v", err)
	}
	for _, p := range m.outstanding {
		if reject {
			m.failed[p.seller] += p.amount
		}
	}
	m.outstanding = nil
}

func (m *ledgerModel) runPending(t *rapid.T) {
	job := app.NewPendingJob(m.h.store, m.h.events, app.PendingConfig{Interval: time.Second, Now: m.h.clock.Now, Logger: m.h.logger})
	if _, err := job.RunOnce(ctx); err != nil {
		t.Fatalf("pending job: %v", err)
	}
}

func (m *ledgerModel) balance(t *rapid.T, code string) int64 {
	var b int64
	if err := m.h.db.QueryRow(ctx, `SELECT coalesce(sum(e.amount), 0)::bigint
		FROM entries e JOIN accounts a ON a.id = e.account_id WHERE a.code = $1`, code).Scan(&b); err != nil {
		t.Fatalf("balance %s: %v", code, err)
	}
	return b
}

// check runs after every action (rapid's "" action).
func (m *ledgerModel) check(t *rapid.T) {
	tb, err := m.h.store.TrialBalance(ctx)
	if err != nil {
		t.Fatalf("trial balance: %v", err)
	}
	if !tb.OK() {
		t.Fatalf("trial balance failed: %+v", tb)
	}
	for _, o := range m.orders {
		want := int64(0)
		if m.paid[o.checkout] && !o.completed && !o.refunded {
			want = -o.amount
		}
		if got := m.balance(t, escrow(o.id)); got != want {
			t.Fatalf("escrow of order %s = %d, want %d (paid=%v completed=%v refunded=%v)",
				o.id, got, want, m.paid[o.checkout], o.completed, o.refunded)
		}
	}
	for i, c := range m.checkouts {
		var want int64
		for _, d := range m.duplicates {
			if d.checkout == i && !d.refunded {
				want -= c.amount()
			}
		}
		if got := m.balance(t, "checkout_suspense:"+c.id.String()); got != want {
			t.Fatalf("suspense of checkout %s = %d, want %d", c.id, got, want)
		}
	}
	for _, s := range m.sellers {
		if got := -m.balance(t, wallet(s)); got != m.available(s) {
			t.Fatalf("available(%s) = %d, want releases %d − requested %d + failed %d",
				s, got, m.released[s], m.requested[s], m.failed[s])
		}
	}
}

# ledger-svc

The double-entry, append-only ledger of the marketplace (P2 WS2'). It is the single source of truth for money positions:
- provider clearing and checkout suspense;
- per-order escrow;
- seller wallets and payouts;
- platform commission.

Every balance is derived by summing entries. No balance is stored anywhere.

- HTTP `:8085`: `/healthz`, `/readyz` (Postgres, Kafka) and the seller wallet API (`api/openapi/ledger.yaml`).
- gRPC `:9085`: the standard health service only.
- Consumes `payment.events` and `order.events` (group `ledger-svc`). Publishes `payout.events` (key `seller_user_id`) through the outbox.
- Spec: `docs/superpowers/specs/2026-09-29-marketplace-p2-ws2-ledger.md`. ADRs 0006 and 0007.

## Layout

| Package | Role |
|---|---|
| `internal/domain` | Chart of accounts, `Journal` (Σ = 0 check) and one builder per posting kind |
| `internal/app` | `Post` (lock → replay check → overdraw check → insert), `EventHandler`, `PendingJob`, `PayoutService`, `SettleJob`, `WalletService`, `TrialBalance` |
| `internal/adapter/postgres` | sqlc queries (`queries/` → `sqlcdb/`, regenerate with `make gen-sqlc`) |
| `internal/adapter/kafka` | Consumer for both topics |
| `internal/adapter/http` | `ledger.yaml` handlers |
| `internal/adapter/bank` | `BankPort` simulator (always succeeds) |
| `internal/bootstrap` | Wiring shared by `cmd/server` and the end-to-end test |

## Invariants and where they are enforced

| Invariant | Database | Code |
|---|---|---|
| Every transaction has ≥ 2 entries summing to 0 | Deferred constraint triggers `entries_balanced`, `journal_transactions_have_entries` | `Journal.Validate` |
| Append-only (`journal_transactions`, `entries`, `escrow_allocations`) | `BEFORE UPDATE/DELETE/TRUNCATE` triggers | Nothing ever updates them |
| No liability account in debit | Deferred trigger `entries_liability_not_in_debit` (backstop) | `Post` locks debited liability accounts `FOR UPDATE` in id order and re-checks the balance |
| Each posting happens once | `UNIQUE (idempotency_key)` | `Post` returns the existing transaction; consumers also record `processed_events` in the same transaction |

## Decisions

- **Permanent vs retryable events.** Events that can never apply are logged at ERROR and skipped, so they never block a partition (`kafkax` retries errors forever):
  - undecodable events, bad ids, invalid amounts and unknown providers;
  - allocations above the payment amount;
  - invariant rejections, such as a refund of a released escrow (`alert=true`).

  Only infrastructure errors and a refund that arrives before its capture are retried.
- **Release and refund amounts come from `escrow_allocations`,** which record what was captured. When an event disagrees, the difference is logged.
- **A second payment naming already-captured orders** keeps its `PAY`, so the money sits in suspense for the duplicate refund. Its capture is skipped with an alert.
- **Payouts:**
  - the minimum (`PAYOUT_MIN_AMOUNT`) is checked before the `Idempotency-Key` claim;
  - `201` and `409 INSUFFICIENT_FUNDS` are both stored and replayed;
  - a claim orphaned by a crash can be reclaimed after 1 minute.
- **`platform_cash` goes negative** as payouts settle, because P2 doesn't model provider settlement (ADR-0006).
